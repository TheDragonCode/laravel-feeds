# GeneratorService documentation hid direct preflight exceptions

**Severity:** Medium

**Files:**
- `docs/docs/api/runtime.mdx`
- `docs/i18n/*/docusaurus-plugin-content-docs/current/api/runtime.mdx`
- `docs/static/llms.txt`

## Problem

The runtime API documentation stated that generation failures are wrapped in `FeedGenerationException` without documenting that storage and output path resolution happen before the generation exception boundary.

## Root Cause

The documentation collapsed preflight and generation into one failure contract even though `GeneratorService::feed()` performs storage and path resolution before its `try` block. The existing behavior test already requires `UnsupportedStorageDiskException` to escape directly during preflight.

## Solution

Documented the direct preflight exception behavior and limited `FeedGenerationException` wrapping to failures after preflight succeeds. Applied the same contract to all eight maintained localizations and regenerated the LLM documentation artifact.

## Prevention

- Derive documented exception boundaries from the actual `try` and `catch` scope.
- Cross-check API prose against behavior tests before describing exception wrapping.
- Update every maintained localization when an API contract changes.
