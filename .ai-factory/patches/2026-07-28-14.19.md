# Yandex category delegation dropped replacement behavior

**Date:** 2026-07-28 14:19
**Files:** src/Presets/Info/YandexFeedInfo.php, tests/Unit/Presets/Info/YandexFeedInfoTest.php
**Severity:** high

## Problem

After `category()` was simplified to delegate category storage to `rawCategory()`, calls with `replace: true` appended the new category instead of removing existing categories. Removing the coverage exclusion from `currency()` also left its replacement branch uncovered.

## Root Cause

The delegation forwarded the generated category array but omitted the existing `$replace` argument. The refactor preserved the public signature while accidentally dropping part of its behavior. Coverage annotations were removed independently from the tests that exercised the corresponding branch.

## Solution

Forwarded `$replace` from `category()` to `rawCategory()`. Added behavior tests proving that both `category()` and `currency()` replace existing entries when requested. The complete suite now reports 100% coverage without excluding these branches.

## Prevention

- Forward every behavioral option when replacing inline logic with method delegation.
- Cover public optional flags through observable behavior before consolidating implementations.
- Replace coverage exclusions and their underlying branches in the same tested change.
