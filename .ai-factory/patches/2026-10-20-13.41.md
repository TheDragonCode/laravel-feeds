# Agent detector mock rejected JSON encoding

**Date:** 2026-10-20 13:41
**Files:** tests/Helpers/mocks.php
**Severity:** low

## Problem

Agent command tests failed with `Received Mockery_2_DragonCode_LaravelFeed_Services_AgentDetectorService::encode(), but no expectations were specified`.

## Root Cause

Commit `d1c4dfc` moved JSON encoding into `AgentService`. The shared test helper still replaced the entire service while configuring only `isAgent()`.

## Solution

Use a partial mock so detection remains controlled and encoding uses the real implementation. Keep the existing JSON assertions unchanged.

The original `php vendor/bin/pest tests/Feature/Console/Generation/AgentTest.php --compact` reproduction changed from two failures to three passing tests with 39 assertions. The full suite passed: 557 tests, 4857 assertions. Pint and `git diff --check` passed.

## Prevention

When moving behavior into a mocked service, check every shared mock and run the existing consumer tests against the real moved behavior.
