# Documentation search and browser CI ignored locale and render environment

**Date:** 2026-08-06 14:54
**Files:** docs/scripts/content-manifest.mjs, docs/src/components/DocSearch/index.tsx, docs/src/theme/MDXComponents.tsx, docs/tests/e2e.spec.ts, .github/workflows/test-docs.yml, tests/Unit/DocumentationWorkflowTest.php
**Severity:** high

## Problem

Documentation search always used English metadata, so translated queries returned no results and localized pages displayed English result titles and descriptions. The documentation workflow also failed its typecheck contract, reported a mobile scrollable-table accessibility violation, and produced visual diffs because CI rendered snapshots outside the image used to create them.

## Root Cause

The generated manifest contained only English routes and the search component selected that global array without reading the active Docusaurus locale. Raw Markdown tables became horizontal scroll regions on mobile without keyboard focus. The pull-request workflow omitted its explicit typecheck command and used the host runner instead of the pinned Playwright browser and font environment. The replacement job container initially lacked shared IPC, which caused Lighthouse Chrome to crash under GitHub Actions.

## Solution

Generated search metadata for every configured locale from translated front matter, headings, and homepage messages, then selected the active locale in the search component. Made Markdown tables keyboard-focusable, restored the explicit typecheck step, and ran browser gates in the Playwright image matching the dependency and committed snapshots with host IPC enabled. Added regression coverage for Russian search and the complete workflow container configuration.

## Prevention

- Generate user-facing indexes from localized sources and test a translated query end to end.
- Keep visual baselines and CI rendering in the same pinned browser image with enough shared memory for Chromium.
- Preserve explicit workflow commands that are enforced by repository tests.
- Run accessibility checks at the responsive breakpoints that introduce scrolling.
