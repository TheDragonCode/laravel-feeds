# Inline-code padding left Linux visual snapshots stale

**Date:** 2026-08-11 23:43
**Files:** `docs/tests/visual.spec.ts-snapshots/api-light-mobile-chromium-linux.png`, `docs/tests/visual.spec.ts-snapshots/faq-expanded-chromium-linux.png`, `docs/tests/visual.spec.ts-snapshots/generation-light-desktop-chromium-linux.png`
**Severity:** medium

## Problem

The documentation workflow failed in `npm run test:browser`. Three Playwright visual tests reported stable differences of 2–3% from their Linux snapshots.

## Root Cause

Commit `4d538e7` added padding to inline code elements but did not regenerate the affected Linux visual snapshots. A later source change triggered the documentation workflow again and exposed the stale baselines.

## Solution

Regenerated the three affected snapshots with `npm run test:visual:update` in the same `mcr.microsoft.com/playwright:v1.62.1-noble` container used by GitHub Actions. Re-ran the visual suite and the complete browser, accessibility, and end-to-end suite.

## Prevention

- Regenerate visual snapshots in the workflow's pinned Playwright container after intentional CSS changes.
- Run `npm run test:browser` before merging documentation presentation changes.
