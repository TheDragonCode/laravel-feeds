# Documentation distillation used an invalid working directory

**Date:** 2026-10-20 18:52
**Files:** dev/distillation-docs.ps1
**Severity:** low

## Problem

The script failed with `Cannot find path 'docsDirectory' because it does not exist.` Its successful path would also leave the caller in the wrong directory, and a failed documentation build could continue into distillation.

## Root Cause

The docs path was computed as the parent of `dev/docs`, and `Push-Location` received the literal `docsDirectory` instead of the variable. Two pushes shared one pop. Native command exit codes were not checked.

## Solution

Build the docs path with `Join-Path`, push it once, and use `Set-Location` for the repository root. Keep one pop in `finally`, and throw on nonzero npm or codex exit codes.

The same stub check failed against the original script and passed after the fix. Five cases passed on both Windows PowerShell 5.1 and PowerShell 7: success, each command returning a nonzero exit code, and each command throwing. Checks covered exact arguments and working directories, paths containing spaces and brackets, and preservation of the caller's directory and existing location stack. Real npm and codex commands were not run.

## Prevention

Use `Join-Path` and variable arguments for literal paths. Pair every location push with one pop, check native exit codes, and verify command failures without invoking the real external tools.
