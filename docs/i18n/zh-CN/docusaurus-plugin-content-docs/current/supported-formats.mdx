# 支持的格式

- **xml** — 生成 XML 格式的 Feed。
- **json** — 生成 JSON 格式的 Feed。
- **jsonl** — 生成 JSON Lines 格式的 Feed。
- **csv** — 生成 CSV 格式的 Feed。
- **rss** — 生成 RSS Atom 格式的 Feed。

默认使用 `xml` 格式。
