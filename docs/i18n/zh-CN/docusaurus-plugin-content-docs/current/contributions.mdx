# 贡献指南

我们**欢迎**贡献，并会充分**注明**贡献者。

我们组织的[所有项目](https://github.com/TheDragonCode)都接受通过 Pull Request 提交的贡献。

## 代码风格 {/* #code_style */}

**Laravel Feeds** 遵循 [PER-3](https://www.php-fig.org/per/coding-style/) 编码标准和 [PSR-4](https://www.php-fig.org/psr/psr-4/) 自动加载标准。

要应用代码风格格式化，请运行以下控制台命令：

```bash
composer style
```

## 行为准则 {/* #code_of_conduct */}

Laravel 行为准则源自 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 行为准则。任何违反行为准则的情况都可以报告给 [Andrey Helldar](mailto:helldar@dragon-code.pro)：

- 参与者应包容不同意见。
- 参与者必须确保自己的言辞和行为不包含人身攻击或贬损性言论。
- 在理解他人的言辞和行为时，参与者应始终以善意为前提。
- 不容忍任何可合理认定为骚扰的行为。
