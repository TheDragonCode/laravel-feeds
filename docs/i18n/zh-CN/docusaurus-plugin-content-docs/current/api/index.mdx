## 扩展点 {/* #extension-points */}

- 继承 `Feed` 或预设，以定义数据源和输出契约。
- 继承 `FeedItem` 和 `FeedInfo`，以控制序列化数据。
- 实现 `DragonCode\LaravelFeed\Contracts\Transformer`，以自定义标量转换。
- 需要省略字段时，返回 `DragonCode\LaravelFeed\Data\OptionalData`。
- 在 `Feed`、`FeedItem` 或 `FeedInfo` 上注册宏，以添加应用级辅助方法。
