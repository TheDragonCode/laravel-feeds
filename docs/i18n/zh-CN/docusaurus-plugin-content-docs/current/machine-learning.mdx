# 机器学习

你可以帮助 LLM 更好地理解此项目的结构和约定。

为此，请导入以下文件中的指南：[**llms.txt**](https://feeds.dragon-code.pro/llms.txt)。

此文件是一份统一的 Markdown 文档，包含该项目编译后的文档。它可用作 LLM 的知识库，例如系统提示词附件、检索语料库或自定义知识文件。

:::note
请保存该 URL，并随着项目演进定期重新导入，以获取更新。
:::
