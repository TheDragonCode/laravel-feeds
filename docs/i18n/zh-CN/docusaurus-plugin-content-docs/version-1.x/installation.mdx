# 安装与设置

你可以通过 [Composer](https://getcomposer.org) 安装此软件包：

```bash
composer require dragon-code/laravel-feeds
```

你应使用以下命令发布[迁移](https://github.com/TheDragonCode/laravel-feeds/blob/main/database/migrations/2025_09_01_231655_create_feeds_table.php)和 [config/feeds.php](https://github.com/TheDragonCode/laravel-feeds/blob/main/config/feeds.php) 配置文件：

```bash
php artisan vendor:publish --tag="feeds"
```

:::warning
**运行迁移之前**，请检查 `config/feeds.php` 文件中的数据库连接设置。
:::

现在可以运行迁移并继续[创建 Feed](./create-feeds.mdx)。

```bash
php artisan migrate
```

对于已有安装，只需将软件包中的 `database/migrations/2026_10_14_000000_add_slug_to_feeds_table.php` 复制到应用的迁移目录。选择文件名的时间戳，使该迁移紧接应用实际的 `create_feeds_table` 迁移，并且位于所有 Feed 注册迁移之前；保留 `add_slug_to_feeds_table` 后缀。然后运行 `php artisan migrate`。该迁移使用配置的连接和表，根据现有标题填充 slug，包括已软删除的记录。不要重新发布或运行原始的建表迁移。将命令和手动调度中的数字 Feed ID 替换为已存储的 slug。
