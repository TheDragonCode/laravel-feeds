# Решение проблем

<PageLead>
Начните с первой границы, где возникает ошибка: регистрация, запрос, преобразование, хранилище или доставка. Сохраняйте исходное исключение: оно содержит класс фида и контекст вывода.
</PageLead>

## Класс фида не найден {/* #feed-class-not-found */}

Проверьте, что запись содержит полное имя класса, автозагрузка Composer может его получить, а класс расширяет `DragonCode\LaravelFeed\Feeds\Feed` или предустановку. После перемещения класса выполните `composer dump-autoload`.

## Генерация использует слишком много памяти {/* #high-memory */}

- Возвращайте `Builder` Eloquent из `builder()`.
- Не вызывайте `get()`, `all()` или `toArray()` для всего набора данных.
- Уменьшите `chunkSize()` и повторите измерение.
- Разделяйте большой вывод через `perFile()`.
- Переносите работу в асинхронную очередь только после сохранения потоковой работы самого фида.

Смотрите [производительность](./performance.mdx).

## Задача очереди не запускается {/* #queue-job */}

Проверьте `FEED_QUEUE_CONNECTION`, `FEED_QUEUE_NAME` и команду обработчика. Подключение `sync` выполняет задачу сразу и не проверяет асинхронную доставку. Блокировка уникальности может не допустить вторую задачу до окончания `FEED_QUEUE_UNIQUE_TTL`.

## Диск хранилища отклонён {/* #storage-disk */}

Диск должен возвращать `Illuminate\Filesystem\FilesystemAdapter` и поддерживать потоки для записи, перемещение, каталоги, списки и удаление. Диски только для чтения и реализации только контракта завершаются ошибкой до запроса в базу данных.

## Генерация XML завершается ошибкой {/* #xml-failure */}

Проверьте необработанный XML из `@mixed`, содержимое CDATA и контракты скалярных значений или массивов для директив. Используйте обычные экранированные значения, если необработанный XML не нужен.

## Строки CSV ошибочны после первого элемента {/* #csv-schema */}

CSV определяет столбцы по схеме вывода. Каждый элемент должен возвращать одинаковые ключи. Необязательные значения сохраняют пустой столбец, а не удаляют его.

## Опубликованные файлы неполные или устаревшие {/* #publication */}

Проверьте исходное исключение хранилища и права диска. На удалённых дисках учитывайте eventual consistency и неатомарные перемещения через копирование и удаление. Генераторам на разных узлах нужна внешняя распределённая блокировка.
