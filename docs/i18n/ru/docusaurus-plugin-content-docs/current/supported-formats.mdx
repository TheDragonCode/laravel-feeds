# Поддерживаемые форматы

- **xml** — генерирует фиды в формате XML.
- **json** — генерирует фиды в формате JSON.
- **jsonl** — генерирует фиды в формате JSON Lines.
- **csv** — генерирует фиды в формате CSV.
- **rss** — генерирует фиды в формате RSS Atom.

По умолчанию используется формат `xml`.
