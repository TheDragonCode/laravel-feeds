# События и исключения

<PageLead>
Используйте события жизненного цикла для интеграции с приложением, а типы исключений — для восстановления на границе, способной обработать сбой.
</PageLead>

## События жизненного цикла {/* #lifecycle-events */}

| Событие | Публичные данные | Момент отправки |
| --- | --- | --- |
| `FeedStartingEvent` | `feed` | После предварительной проверки хранилища и пути, до разрешения конвертера и подготовки файлов. |
| `FeedFinishedEvent` | `feed`, `path`, `paths` | После успешной публикации всех сгенерированных файлов. |

`FeedFinishedEvent::$paths` содержит все опубликованные пути по порядку. `$path` сохранено для совместимости и всегда содержит первый путь.

## Ошибки ввода и поиска {/* #input-and-lookup-failures */}

| Исключение | Значение |
| --- | --- |
| `InvalidFeedArgumentException` | Идентификатор фида в консоли некорректен. |
| `FeedNotFoundException` | Запись с запрошенным идентификатором не существует. |
| `InvalidExpressionException` | Выражение расписания некорректно. |
| `UnknownFeedClassException` | Настроенный класс фида невозможно получить. |
| `UnexpectedClassException` | Полученный класс не соответствует ожидаемому контракту. |

## Ошибки сериализации и хранилища {/* #serialization-and-storage-failures */}

| Исключение | Значение |
| --- | --- |
| `InvalidCsvRowException` | Строка CSV не соответствует заданной схеме столбцов. |
| `InvalidCsvValueException` | Поле CSV невозможно сериализовать как скалярное значение. |
| `InvalidXmlCDataException` | Значение CDATA некорректно. |
| `InvalidXmlFragmentException` | Необработанный фрагмент XML некорректен. |
| `UnsupportedStorageDiskException` | Выбранный диск Laravel не разрешается в `FilesystemAdapter`. |
| `OpenFeedException` | Невозможно открыть черновой ресурс вывода. |
| `WriteFeedException` | Невозможно полностью записать вывод. |
| `CloseFeedException` | Невозможно закрыть ресурс вывода. |
| `ResourceMetaException` | Обязательные метаданные потока недоступны. |
| `FeedGenerationException` | Генерация конкретного класса фида завершилась ошибкой. |

Перехватывайте исключения только там, где приложение может добавить восстановление или понятный контекст. Неисправимые ошибки генерации должен сообщать Laravel.
