## Точки расширения {/* #extension-points */}

- Расширьте `Feed` или предустановку, чтобы задать источник данных и контракт вывода.
- Расширьте `FeedItem` и `FeedInfo`, чтобы управлять сериализованными данными.
- Реализуйте `DragonCode\LaravelFeed\Contracts\Transformer` для пользовательского преобразования скалярных значений.
- Возвращайте `DragonCode\LaravelFeed\Data\OptionalData`, если поле нужно пропустить.
- Регистрируйте макросы в `Feed`, `FeedItem` или `FeedInfo` для вспомогательных методов приложения.
