# Фиды и данные

<PageLead>
Основной API разделяет источник данных, отображение элемента, метаданные фида, структуру вывода и результат генерации.
</PageLead>

## Feed {/* #feed */}

`DragonCode\LaravelFeed\Feeds\Feed` — базовый класс экспорта. Реализуйте `builder()` и переопределяйте только нужные фиду точки вывода.

<ApiSignature>abstract public function builder(): Builder</ApiSignature>

| Метод | Значение по умолчанию | Контракт |
| --- | --- | --- |
| `builder(): Builder` | Абстрактный | Возвращает запрос Eloquent, используемый как источник данных. |
| `item(Model $model): FeedItem` | Новый базовый `FeedItem` | Преобразует одну модель в элемент вывода. |
| `transformers(): array` | `[]` | Добавляет имена классов преобразователей в начало для этого фида. |
| `chunkSize(): int` | `1000` | Размер блока запроса к базе данных. |
| `perFile(): int` | `0` | Количество записей в файле. Ноль отключает разделение по количеству. |
| `maxFiles(): int` | `0` | Максимальное количество файлов. Ноль не ограничивает его. |
| `header(): string` | Декларация XML для XML/RSS | Содержимое перед корнем и элементами. |
| `footer(): string` | Пустая строка | Содержимое после корня и элементов. |
| `root(): ElementData` | Имя элемента из имени класса | Определяет корневой элемент и атрибуты. |
| `info(): FeedInfo` | Пустой `FeedInfo` | Определяет информацию уровня фида. |
| `filename(): string` | Имя файла из имени класса | Возвращает имя выходного файла относительно диска. |
| `path($suffix): string` | Путь от адаптера | Возвращает локальный или определённый адаптером путь. |
| `storagePath($suffix): string` | Имя файла относительно диска | Возвращает путь для операций с хранилищем. |
| `storage(): FilesystemAdapter` | Диск `public` | Получает и проверяет диск файловой системы Laravel. |
| `format(): FeedFormatEnum` | `Xml` | Возвращает настроенный формат вывода. |

`Feed` использует Laravel `Conditionable` и `Macroable`.

## FeedItem и FeedInfo {/* #feed-item-and-feed-info */}

`FeedItem` получает текущую модель Eloquent. Его стандартные значения:

- `name()` возвращает базовое имя класса модели в kebab case;
- `attributes()` возвращает пустой массив;
- `toArray()` возвращает массив модели.

`FeedInfo::toArray()` возвращает пустой массив. Оба класса используют `Conditionable` и `Macroable`; расширяйте их, если выводу нужна явная схема.

## ElementData {/* #element-data */}

`ElementData` — объект только для чтения с тремя свойствами конструктора:

| Свойство | Тип | Значение по умолчанию |
| --- | --- | --- |
| `name` | `?string` | `null` |
| `attributes` | `array` | `[]` |
| `beforeInfo` | `bool` | `true` |

Задайте `name` как `null` или пустую строку, чтобы не выводить корневой элемент. Задайте `beforeInfo` как `false`, чтобы записать информацию фида перед корнем.

## Результат генерации {/* #generation-result */}

`GeneratorService::feed()` возвращает `GenerationResultData`. Свойство только для чтения `paths` содержит опубликованные файлы по порядку. `records` сопоставляет каждому пути количество записей в файле.

Методы программной генерации и регистрации перечислены в [сервисах и контрактах выполнения](./runtime.mdx).
