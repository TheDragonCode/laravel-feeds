# Машинное обучение

Вы можете помочь своей LLM значительно лучше понять структуру и правила этого проекта.

Для этого импортируйте инструкции из файла [**llms.txt**](https://feeds.dragon-code.pro/llms.txt).

Это единый документ Markdown, содержащий собранную документацию проекта. Он предназначен для использования как база знаний для LLM, например как вложение к системному промпту, корпус для поиска или пользовательский файл знаний.

:::note
Сохраните URL и периодически импортируйте файл заново, чтобы получать обновления по мере развития проекта.
:::
