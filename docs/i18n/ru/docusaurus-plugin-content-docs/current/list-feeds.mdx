# Список зарегистрированных фидов {/* #list_feeds */}

Начиная с версии 2.1.0 можно просматривать записи фидов без генерации файлов или изменения их состояния:

```bash
php artisan feed:list
```

У команды нет собственных аргументов или параметров. Она показывает таблицу всех записей, включая неактивные и мягко удалённые фиды.

| Столбец | Значение |
| --- | --- |
| `id` | Идентификатор записи. |
| `slug` | Slug записи, который использует `feed:generate`. |
| `title` | Название записи. |
| `expression` | Сохранённое cron-выражение. |
| `is_active` | Включена ли запись. |
| `is_deleted` | Мягко ли удалена запись. |
| `last_activity` | Последнее сохранённое время генерации в формате ISO 8601; `null` в JSON, если не задано. |

Сначала выводятся неудалённые записи, затем — мягко удалённые. В каждой группе активные фиды идут первыми, дальше строки сортируются по названию и идентификатору. Логические значения в консоли выводятся как `true` или `false`.

Чтобы сгенерировать фид, используйте slug неудалённой записи:

```bash
php artisan feed:generate products
```

Если записей нет, консоль выводит `No feeds available`.

## Список для ИИ-агента {/* #list_feeds_agent */}

Внутри распознанного ИИ-агента для работы с кодом `feed:list` автоматически возвращает один компактный объект JSON одной строкой. Дополнительный параметр не требуется. Логические поля остаются логическими значениями JSON:

```json
{
  "tool": "feed:list",
  "result": "success",
  "feeds": [
    {
      "id": 1,
      "slug": "products",
      "title": "Products",
      "expression": "0 * * * *",
      "is_active": true,
      "is_deleted": false,
      "last_activity": null
    }
  ]
}
```

Пример отформатирован для удобства чтения. Пустой список возвращается в той же оболочке с `"feeds": []`.
