# Руководство по обновлению

<PageLead>
Документация описывает ветку `1.x`. Перед каждым обновлением проверяйте примечания к выпуску и файл блокировки зависимостей.
</PageLead>

## Перед обновлением {/* #before-upgrading */}

1. Убедитесь, что целевая версия поддерживает версии PHP и Laravel приложения.
2. Зафиксируйте `composer.lock` и текущий опубликованный `config/feeds.php`.
3. Запишите активные фиды и места выходных файлов.
4. Запустите тесты генерации или создайте типовые фиды вне production.

## Применение обновления {/* #apply-update */}

```bash
composer update dragon-code/laravel-feeds --with-all-dependencies
php artisan migrate
```

Сравните `config/feeds.php` установленного пакета с опубликованной копией приложения и добавьте новые ключи вручную. Не публикуйте повторно с `--force`: это перезаписывает настройки приложения.

## Проверка {/* #verify */}

- Сгенерируйте по одному фиду каждого используемого формата.
- Проверьте количество разделённых файлов и их имена.
- Проверьте генерацию по расписанию и через очередь.
- Проверьте пользовательские модели, преобразователи, макросы и классы предустановок.
- Сравните типовой вывод с предыдущей версией.

## Откат {/* #rollback */}

Восстановите предыдущие `composer.lock` и конфигурацию, выполните `composer install` и примените политику отката миграций. Сгенерированные файлы — артефакты развёртывания; восстановите или создайте их заново по плану восстановления хранилища.
