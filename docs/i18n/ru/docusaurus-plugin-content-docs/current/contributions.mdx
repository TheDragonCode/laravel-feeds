# Руководство по участию

Мы **приветствуем** ваш вклад и обязательно **отметим** его.

Мы принимаем вклад через Pull Request во [всех проектах](https://github.com/TheDragonCode) нашей организации.

## Стиль кода {/* #code_style */}

**Laravel Feeds** следует стандарту оформления кода [PER-3](https://www.php-fig.org/per/coding-style/) и стандарту автозагрузки [PSR-4](https://www.php-fig.org/psr/psr-4/).

Чтобы применить форматирование кода, выполните следующую консольную команду:

```bash
composer style
```

## Кодекс поведения {/* #code_of_conduct */}

Кодекс поведения Laravel основан на кодексе [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). О любом нарушении кодекса можно сообщить [Andrey Helldar](mailto:helldar@dragon-code.pro):

- Участники должны терпимо относиться к противоположным взглядам.
- Участники должны следить, чтобы в их словах и действиях не было личных нападок и унизительных замечаний.
- При толковании слов и действий других людей участники всегда должны исходить из добрых намерений.
- Поведение, которое можно обоснованно считать домогательством или травлей, не допускается.
