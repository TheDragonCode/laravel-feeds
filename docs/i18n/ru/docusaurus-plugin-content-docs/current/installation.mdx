# Установка и настройка

Пакет можно установить через [Composer](https://getcomposer.org):

```bash
composer require dragon-code/laravel-feeds
```

Опубликуйте [миграцию](https://github.com/TheDragonCode/laravel-feeds/blob/main/database/migrations/2025_09_01_231655_create_feeds_table.php) и файл конфигурации [config/feeds.php](https://github.com/TheDragonCode/laravel-feeds/blob/main/config/feeds.php) следующей командой:

```bash
php artisan vendor:publish --tag="feeds"
```

:::warning
**Перед запуском миграций** проверьте настройки подключения к базе данных в файле `config/feeds.php`.
:::

Теперь можно запустить миграции и перейти к [созданию фидов](./create-feeds.mdx).

```bash
php artisan migrate
```
