# События

При выполнении команды фиды отправляют два события:

- **`DragonCode\LaravelFeed\Events\FeedStartingEvent`** — событие `FeedStartingEvent` отправляется непосредственно перед созданием чернового файла.
- **`DragonCode\LaravelFeed\Events\FeedFinishedEvent`** — событие `FeedFinishedEvent` отправляется после успешной публикации всех сгенерированных файлов. Если генерация завершилась ошибкой, это событие не отправляется.

## Контракт события завершения {/* #finished_event_contract */}

Событие завершения предоставляет следующие публичные свойства:

- `$feed` содержит класс сгенерированного фида.
- `$paths` содержит все пути опубликованных файлов в порядке вывода.
- `$path` остаётся доступным для обратной совместимости и содержит путь к первому опубликованному файлу. Используйте `$paths`, если фид может быть разделён на несколько файлов.

`GeneratorService::feed()` возвращает объект `GenerationResultData`. Его свойство `$paths` содержит те же упорядоченные пути, а `$records` сопоставляет каждому пути количество записей, записанных в соответствующий файл.
