# Совместимость

<PageLead>
Используйте граф зависимостей, разрешённый Composer, как окончательную проверку совместимости конкретного приложения.
</PageLead>

## Матрица выполнения {/* #runtime-matrix */}

<ResponsiveTable label="Laravel Feeds runtime compatibility">

| Компонент | Поддерживаемые версии |
| --- | --- |
| PHP | `8.2` и более новые версии `8.x`, разрешённые ограничениями установленного пакета |
| Компоненты Laravel | `11.x`, `12.x`, `13.x` |
| База данных | Любое подключение Laravel, поддерживаемое настроенной моделью Eloquent и миграцией |
| Файловая система | Доступные для записи диски Laravel, возвращающие `FilesystemAdapter` |

</ResponsiveTable>

Установленный `composer.lock` — окончательный источник для конкретного приложения. Composer отклоняет неподдерживаемые сочетания.

## Форматы вывода {/* #output-formats */}

| Формат | Расширение | Вложенные данные | Директивы XML |
| --- | --- | --- | --- |
| XML | `.xml` | Да | Да |
| JSON | `.json` | Да | Нет |
| JSON Lines | `.jsonl` | Одно значение JSON в строке | Нет |
| CSV | `.csv` | Нет; нужны стабильные скалярные столбцы | Нет |
| RSS | `.rss` | Да | Да |

## Необязательные интеграции {/* #optional-integrations */}

- Laravel Queue нужна только при включённом режиме очереди.
- Если Laravel Deploy Operations установлен, его использует `make:feed`; иначе команда создаёт миграцию.
- Необязательные значения Spatie Laravel Data распознаются, если пакет установлен.
