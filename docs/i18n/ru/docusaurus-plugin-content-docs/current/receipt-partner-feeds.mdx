# Несколько целевых файлов фида

Этот рецепт регистрирует один `PartnerFeed` и с помощью целей фида создаёт несколько XML-файлов. Каждая цель передаёт параметры: `builder()` использует их для индивидуальных условий выборки, а `filename()` — для отдельного пути. Партнёр здесь только пример: целью может быть магазин, локаль, регион или любое другое бизнес-условие.

## Цели фида и perFile() {/* #targets-vs-per-file */}

`perFile()` делит результат одного запроса на последовательные файлы после заданного количества записей. Запрос и условия выборки для этих файлов не меняются.

`FeedTarget` запускает фид отдельно для каждой цели. Приложение может использовать `target()`, чтобы менять условия запроса и имя файла для каждого вывода. Механизмы можно сочетать: сначала выбрать целевой набор данных, затем разделить его по количеству записей.

В этом примере создаются следующие целевые файлы:

```text
storage/app/public/partners/42.xml
storage/app/public/partners/81.xml
```

## Создание фида {/* #create-feed */}

```bash
php artisan make:feed Partner
```

## Настройка вывода по партнёрам {/* #configure-partner-outputs */}

Замените сгенерированный класс фида следующим кодом:

```php source="docs/snippets/targeted-feed.php"
<?php

declare(strict_types=1);

namespace App\Feeds;

use App\Models\Partner;
use App\Models\Product;
use DragonCode\LaravelFeed\Concerns\InteractsWithFeedTargets;
use DragonCode\LaravelFeed\Contracts\HasFeedTargets;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\FeedTarget;
use Illuminate\Database\Eloquent\Builder;

class PartnerFeed extends Feed implements HasFeedTargets
{
    use InteractsWithFeedTargets;

    public function targets(): iterable
    {
        foreach (Partner::query()->select('id')->lazyById() as $partner) {
            yield $this->makeTarget($partner);
        }
    }

    public function findTarget(string $key): ?FeedTarget
    {
        $partner = Partner::query()->find($key);

        if (! $partner || (string) $partner->getKey() !== $key) {
            return null;
        }

        return $this->makeTarget($partner);
    }

    public function builder(): Builder
    {
        return Product::query()->where(
            'partner_id',
            $this->target()->parameters['partner_id'],
        );
    }

    public function filename(): string
    {
        return "partners/{$this->target()->key}.xml";
    }

    private function makeTarget(Partner $partner): FeedTarget
    {
        return new FeedTarget(
            key       : (string) $partner->getKey(),
            parameters: ['partner_id' => $partner->getKey()],
        );
    }
}
```

`targets()` лениво перечисляет партнёров для полного запуска. `findTarget()` находит явно запрошенные ключи без загрузки всех партнёров. `builder()` фильтрует товары для активного партнёра, а `filename()` задаёт каждому партнёру уникальный путь.

## Генерация файлов всех партнёров {/* #generate-all */}

Передайте идентификатор регистрации фида. Команда сгенерирует файл для каждого партнёра, возвращённого `targets()`:

```bash
php artisan feed:generate 123
```

Для партнёров `42` и `81` будут созданы следующие пути:

```text
storage/app/public/partners/42.xml
storage/app/public/partners/81.xml
```

## Генерация файлов выбранных партнёров {/* #generate-selected */}

Используйте повторяемый параметр `--target`, если нужно обновить файлы только определённых партнёров:

```bash
php artisan feed:generate 123 --target=42
php artisan feed:generate 123 --target=42 --target=81
```

## Разделение вывода партнёра по количеству записей {/* #split-each-output */}

Добавьте `perFile()`, если вывод одного партнёра также может стать слишком большим:

```php
public function perFile(): int
{
    return 50000;
}
```

Тогда партнёр `42` может создать `partners/42-1.xml`, `partners/42-2.xml` и следующие части. Такое разделение по количеству записей применяется независимо для каждого партнёра.
