# Maschinelles Lernen

Sie können Ihrem LLM helfen, die Struktur und Konventionen dieses Projekts wesentlich besser zu verstehen.

Importieren Sie dazu die Anleitung aus der folgenden Datei: [**llms.txt**](https://feeds.dragon-code.pro/llms.txt).

Diese Datei ist ein einzelnes, konsolidiertes Markdown-Dokument mit der zusammengestellten Dokumentation dieses Projekts. Sie dient als Wissensbasis für LLMs, beispielsweise als Anhang zu einem System-Prompt, als Retrieval-Korpus oder als benutzerdefinierte Wissensdatei.

:::note
Speichern Sie die URL und importieren Sie die Datei regelmäßig erneut, um Aktualisierungen des Projekts zu übernehmen.
:::
