# Beitragsleitfaden

Beiträge sind **willkommen** und werden vollständig **gewürdigt**.

Wir nehmen Beiträge über Pull Requests zu [allen Projekten](https://github.com/TheDragonCode) unserer Organisation an.

## Codestil {/* #code_style */}

**Laravel Feeds** folgt dem Codierungsstandard [PER-3](https://www.php-fig.org/per/coding-style/) und dem Autoloading-Standard [PSR-4](https://www.php-fig.org/psr/psr-4/).

Führen Sie den folgenden Konsolenbefehl aus, um den Codestil anzuwenden:

```bash
composer style
```

## Verhaltenskodex {/* #code_of_conduct */}

Der Laravel-Verhaltenskodex basiert auf dem Verhaltenskodex des [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Verstöße gegen den Verhaltenskodex können [Andrey Helldar](mailto:helldar@dragon-code.pro) gemeldet werden:

- Teilnehmer sollten gegenüber abweichenden Ansichten tolerant sein.
- Teilnehmer müssen sicherstellen, dass ihre Sprache und ihr Verhalten frei von persönlichen Angriffen und herabwürdigenden persönlichen Bemerkungen sind.
- Bei der Auslegung der Worte und Handlungen anderer sollten Teilnehmer stets gute Absichten unterstellen.
- Verhalten, das vernünftigerweise als Belästigung angesehen werden kann, wird nicht toleriert.
