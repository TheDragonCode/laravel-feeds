# Installation und Einrichtung

Sie können das Paket über [Composer](https://getcomposer.org) installieren:

```bash
composer require dragon-code/laravel-feeds
```

Veröffentlichen Sie die [Migration](https://github.com/TheDragonCode/laravel-feeds/blob/main/database/migrations/2025_09_01_231655_create_feeds_table.php) und die Konfigurationsdatei [config/feeds.php](https://github.com/TheDragonCode/laravel-feeds/blob/main/config/feeds.php) mit folgendem Befehl:

```bash
php artisan vendor:publish --tag="feeds"
```

:::warning
Prüfen Sie **vor dem Ausführen der Migrationen** die Einstellungen der Datenbankverbindung in der Datei `config/feeds.php`.
:::

Nun können Sie die Migrationen ausführen und anschließend [Feeds erstellen](./create-feeds.mdx).

```bash
php artisan migrate
```

Kopieren Sie bei einer bestehenden Installation nur `database/migrations/2026_10_14_000000_add_slug_to_feeds_table.php` aus dem Paket in das Migrationsverzeichnis Ihrer Anwendung. Wählen Sie für den Dateinamen einen Zeitstempel unmittelbar nach der tatsächlichen `create_feeds_table`-Migration der Anwendung und vor allen Migrationen zur Feed-Registrierung; behalten Sie das Suffix `add_slug_to_feeds_table` bei. Führen Sie dann `php artisan migrate` aus. Die Migration verwendet die konfigurierte Verbindung und Tabelle und erzeugt Slugs aus bestehenden Titeln, einschließlich vorläufig gelöschter Datensätze. Veröffentlichen Sie die ursprüngliche Migration zum Erstellen der Tabelle nicht erneut und führen Sie sie nicht erneut aus. Ersetzen Sie numerische Feed-IDs in Befehlen und manuellen Zeitplänen durch die gespeicherten Slugs.
