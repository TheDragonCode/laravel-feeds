# Feeds erstellen

:::note
Am bequemsten lassen sich die benötigten Klassen mit dem Plugin [Laravel Idea](https://laravel-idea.com) für [PhpStorm](https://www.jetbrains.com/phpstorm/) erstellen.

<ThemedImage
  alt="Laravel Idea"
  sources={{
    light: '/img/laravel-idea.png',
    dark: '/img/laravel-idea_dark.png',
  }}
/>
:::

Verwenden Sie den Konsolenbefehl `make:feed`, um eine Feed-Klasse zu erstellen:

```bash
php artisan make:feed <name>
```

Dadurch wird eine Feed-Datei erstellt, beispielsweise `app/Feeds/UserFeed.php`.

Dieser Konsolenbefehl kann zusammen mit der Feed-Klasse auch die Klassen für Elemente und Informationen erstellen. Verwenden Sie dazu die Optionen `--item` und `--info`.

```bash
# Create a feed class and info class
php artisan make:feed <name> --info

# Create a feed class and item class
php artisan make:feed <name> --item

# Create a feed class, item class, and info class
php artisan make:feed <name> --item --info
```

Außerdem stehen Kurzformen zur Verfügung:

```bash
# Create a feed class and item class
php artisan make:feed <name> -t

# Create a feed class and info class
php artisan make:feed <name> -i

# Create a feed class, item class, and info class
php artisan make:feed <name> -it
```

:::note
Beim Erstellen eines Feeds wird zusätzlich eine Operation oder eine Migration erzeugt, um ihn zur Datenbank hinzuzufügen.

Wenn das Projekt [**Laravel Deploy Operations**](https://deploy-operations.dragon-code.pro) verwendet, wird eine Operationsklasse erstellt. Andernfalls wird eine Migrationsklasse erstellt.

Dies ist erforderlich, um Feed-Informationen in der Datenbank hinzuzufügen und zu verwalten.
:::

## Feeds befüllen {/* #fill_feeds */}

### Feed {/* #feed */}

Befüllen Sie die Hauptklasse des Feeds. Beispiel:

```php source="docs/snippets/create-feeds-feed.php" lines="5-"
namespace App\Feeds;

use App\Feeds\Items\UserFeedItem;
use App\Models\User;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class UserFeed extends Feed
{
    public function builder(): Builder
    {
        return User::query()
            ->whereNotNull('email_verified_at')
            ->where('created_at', '>', now()->subYear());
    }

    public function item(Model $model): FeedItem
    {
        return new UserFeedItem($model);
    }
}
```

#### Feed-Element {/* #feed_item */}

Befüllen Sie die Klasse des Feed-Elements. Beispiel:

```php source="docs/snippets/generation-feed-item.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

/** @property-read \App\Models\User $model */
class UserFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name'  => $this->model->name,
            'email' => $this->model->email,
        ];
    }
}
```

##### Optionale Werte {/* #optional_values */}

Geben Sie eine Instanz von `DragonCode\LaravelFeed\Data\OptionalData` als Wert zurück, um ein Feld auszulassen, wenn sein Wert nicht verfügbar ist:

```php source="docs/snippets/optional-values.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Data\OptionalData;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

class UserFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'id'   => $this->model->id,
            'name' => $this->model->name,

            'cityId' => $this->model->city?->id ?? new OptionalData,

            'createdAt' => $this->model->created_at,
            'updatedAt' => $this->model->updated_at ?? new OptionalData,
        ];
    }
}
```

Optionale Felder werden aus JSON- und JSON-Lines-Objekten sowie aus XML- und RSS-Elementen entfernt. Dies gilt auch für regulär verschachtelte Felder. CSV behält die Spaltenposition bei und schreibt ein leeres Feld.

Wenn Ihre Anwendung [Spatie Laravel Data](https://spatie.be/docs/laravel-data/v4/as-a-data-transfer-object/optional-properties) verwendet, können Sie stattdessen `Spatie\LaravelData\Optional` zurückgeben. Beide Klassen für optionale Werte werden automatisch verarbeitet.

```php
use Spatie\LaravelData\Optional;

'updatedAt' => $this->model->updated_at ?? Optional::create(),
```

## Zielbasierte Feeds {/* #targeted_feeds */}

Verwenden Sie einen zielbasierten Feed, wenn eine registrierte Feed-Klasse für jeden Partner, Shop, jedes Gebietsschema oder ein anderes anwendungsdefiniertes Ziel eine eigenständige Ausgabe erzeugen soll. Die Tabelle `feeds` enthält weiterhin nur eine Zeile für die Feed-Klasse.

Implementieren Sie `HasFeedTargets`. Der mitgelieferte Trait `InteractsWithFeedTargets` stellt das Standardverhalten für `forTarget()` und `target()` bereit; die Feed-Klasse übernimmt die verzögerte Aufzählung und direkte Suche:

```php source="docs/snippets/targeted-feed.php" lines="5-"
namespace App\Feeds;

use App\Models\Partner;
use App\Models\Product;
use DragonCode\LaravelFeed\Concerns\InteractsWithFeedTargets;
use DragonCode\LaravelFeed\Contracts\HasFeedTargets;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\FeedTarget;
use Illuminate\Database\Eloquent\Builder;

class PartnerFeed extends Feed implements HasFeedTargets
{
    use InteractsWithFeedTargets;

    public function targets(): iterable
    {
        foreach (Partner::query()->select('id')->lazyById() as $partner) {
            yield $this->makeTarget($partner);
        }
    }

    public function findTarget(string $key): ?FeedTarget
    {
        $partner = Partner::query()->find($key);

        return $partner ? $this->makeTarget($partner) : null;
    }

    public function builder(): Builder
    {
        return Product::query()->where(
            'partner_id',
            $this->target()->parameters['partner_id'],
        );
    }

    public function filename(): string
    {
        return "partners/{$this->target()->key}.xml";
    }

    private function makeTarget(Partner $partner): FeedTarget
    {
        return new FeedTarget(
            key       : (string) $partner->getKey(),
            parameters: ['partner_id' => $partner->getKey()],
        );
    }
}
```

- `targets()` wird für die nicht konfigurierte Feed-Definition aufgerufen und verzögert verarbeitet, wenn ein Befehl oder Zeitplan alle Ziele erzeugt.
- `findTarget()` führt für jeden expliziten `--target`-Schlüssel eine Suche unter Beachtung der Groß-/Kleinschreibung aus. Geben Sie `null` zurück, wenn der Schlüssel nicht existiert; andernfalls ein Ziel mit dem angeforderten Schlüssel.
- `FeedTarget::$key` darf nicht leer sein, muss stabil, innerhalb der Feed-Klasse eindeutig und für die Ausgabe geeignet sein. Schlüssel werden weder normalisiert noch bereinigt und erscheinen in der Konsolenausgabe, im Agenten-JSON, in Ereignissen und im Fehlerkontext.
- `FeedTarget::$parameters` ist ein anwendungseigener Snapshot, der in Queue-Jobs gespeichert wird. Das Paket wertet ihn nicht aus. Halten Sie ihn klein, serialisierbar und frei von Geheimnissen; speichern Sie Kennungen statt Eloquent-Modellen.
- `target()` gibt das aktive Ziel innerhalb von `builder()`, `filename()` und anderen Ausführungspunkten zurück. Bevor der Feed mit `forTarget()` konfiguriert wurde, löst die Methode eine `LogicException` aus.

:::warning
Jedes Ziel muss einen eigenen Ausgabedateinamen ergeben. Andernfalls überschreiben spätere Ziele frühere Ausgaben. Verwenden Sie einen Zielschlüssel nur dann in einem Pfad, wenn die Anwendung sein Format kontrolliert.
:::

Die normale Dateiaufteilung gilt weiterhin getrennt für jedes Ziel. Beispielsweise wird `partners/42.xml` zu `partners/42-1.xml`, `partners/42-2.xml` und so weiter.

Normale Feed-Klassen implementieren `HasFeedTargets` nicht und müssen nicht geändert werden.

## Dateiformat {/* #file_format */}

:::tip
Die verfügbaren Formate finden Sie auf der Seite [Unterstützte Formate](./supported-formats.mdx).
:::

Sie können Feeds in verschiedenen Formaten erzeugen. Eine Feed-Klasse kann nur korrekt in das Format exportiert werden, für das sie vorgesehen ist. Der Grund dafür sind [Direktiven](./directives.mdx) und weitere formatspezifische Besonderheiten.

Überschreiben Sie einfach die Eigenschaft `$format` in der Feed-Klasse, um das gewünschte Format festzulegen:

```php source="docs/snippets/create-feeds-feed-format.php" lines="5-"
namespace App\Feeds;

use DragonCode\LaravelFeed\Enums\FeedFormatEnum;
use DragonCode\LaravelFeed\Feeds\Feed;
use Illuminate\Database\Eloquent\Builder;

class UserFeed extends Feed
{
    protected FeedFormatEnum $format = FeedFormatEnum::Json;

    public function builder(): Builder
    {
        //
    }
}
```
