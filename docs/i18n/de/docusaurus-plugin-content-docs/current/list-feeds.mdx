# Registrierte Feeds auflisten {/* #list_feeds */}

Ab Version 2.1.0 können Sie Feed-Registrierungen auflisten, ohne Dateien zu erzeugen oder ihren Zustand zu ändern:

```bash
php artisan feed:list
```

Der Befehl hat keine eigenen Argumente oder Optionen. Er zeigt eine Tabelle aller Registrierungen an, einschließlich inaktiver und vorläufig gelöschter Feeds.

| Spalte | Bedeutung |
| --- | --- |
| `id` | ID der Registrierung. |
| `slug` | Registrierungs-Slug, der von `feed:generate` verwendet wird. |
| `title` | Titel der Registrierung. |
| `expression` | Gespeicherter Cron-Ausdruck. |
| `next_run` | Nächster Cron-Zeitpunkt im Format ISO 8601 mit UTC-Offset; `null` in JSON, wenn nicht verfügbar. |
| `is_active` | Ob die Registrierung aktiviert ist. |
| `is_deleted` | Ob die Registrierung vorläufig gelöscht ist. |
| `last_activity` | Zuletzt gespeicherter Generierungszeitpunkt im Format ISO 8601; `null` in JSON, wenn nicht gesetzt. |

Zuerst erscheinen nicht gelöschte Registrierungen, danach vorläufig gelöschte. Innerhalb jeder Gruppe stehen aktive Feeds zuerst; anschließend werden die Zeilen nach Titel und ID sortiert. Boolesche Werte werden in der Konsole als `true` oder `false` angezeigt.

`next_run` verwendet `app.schedule_timezone` und andernfalls `app.timezone`. Das Format ist `YYYY-MM-DDTHH:mm:ss±HH:mm`, zum Beispiel `2025-09-04T09:00:00-04:00`. Der Wert zeigt den nächsten Zeitpunkt des gespeicherten Cron-Ausdrucks auch für inaktive oder vorläufig gelöschte Registrierungen; er garantiert nicht, dass der Feed ausgeführt wird. Hat der Ausdruck keinen möglichen Ausführungszeitpunkt, etwa `0 0 31 2 *`, ist der Wert in JSON `null` und in der Konsole leer.

Verwenden Sie den Slug einer nicht gelöschten Registrierung, um diesen Feed zu erzeugen:

```bash
php artisan feed:generate products
```

Wenn keine Registrierungen vorhanden sind, zeigt die Konsole `No feeds available` an.

## Auflistung für KI-Agenten {/* #list_feeds_agent */}

Innerhalb eines erkannten KI-Coding-Agenten gibt `feed:list` automatisch ein kompaktes JSON-Objekt in einer einzigen Zeile zurück. Es ist keine zusätzliche Option erforderlich. Boolesche Felder bleiben boolesche JSON-Werte:

```json
{
  "tool": "feed:list",
  "result": "success",
  "feeds": [
    {
      "id": 1,
      "slug": "products",
      "title": "Products",
      "expression": "0 * * * *",
      "next_run": "2025-09-04T05:00:00+00:00",
      "is_active": true,
      "is_deleted": false,
      "last_activity": null
    }
  ]
}
```

Das Beispiel ist zur besseren Lesbarkeit formatiert. Eine leere Auflistung liefert dieselbe Hülle mit `"feeds": []`.
