## Erweiterungspunkte {/* #extension-points */}

- Erweitern Sie `Feed` oder eine Voreinstellung, um Datenquelle und Ausgabevertrag zu definieren.
- Erweitern Sie `FeedItem` und `FeedInfo`, um serialisierte Daten zu steuern.
- Implementieren Sie `DragonCode\LaravelFeed\Contracts\Transformer` für eine eigene Umwandlung skalarer Werte.
- Geben Sie `DragonCode\LaravelFeed\Data\OptionalData` zurück, wenn ein Feld ausgelassen werden soll.
- Registrieren Sie Makros auf `Feed`, `FeedItem` oder `FeedInfo` für anwendungsspezifische Hilfsmethoden.
