# Erste Schritte

<PageLead>
Installieren Sie das Paket, definieren Sie eine Eloquent-Abfrage und die Struktur eines Elements und erzeugen Sie anschließend eine Feed-Datei. In einer vorhandenen Laravel-Anwendung dauert der erste funktionierende Export etwa fünf Minuten.
</PageLead>

## Voraussetzungen {/* #prerequisites */}

- PHP `8.2` oder eine neuere, von Composer akzeptierte Version aus der Reihe `8.x`
- Laravel `11.x`, `12.x` oder `13.x`
- Eine konfigurierte Datenbank und ein Dateisystem-Datenträger

## Installation und Vorbereitung {/* #install-and-prepare */}

```bash
composer require dragon-code/laravel-feeds
php artisan vendor:publish --tag="feeds"
php artisan migrate
php artisan make:feed User --item
```

Der Generator erstellt die Feed- und Elementklassen. Außerdem erstellt er die Datenbankänderung zur Registrierung des Feeds. Führen Sie diese Migration vor der ersten Generierung aus, falls sie nach dem vorherigen `migrate`-Befehl erzeugt wurde.

## Datenquelle definieren {/* #define-the-data-source */}

Geben Sie einen Eloquent-Builder zurück, damit Datensätze in Chunks gelesen werden können.

```php source="docs/snippets/create-feeds-feed.php" lines="5-"
namespace App\Feeds;

use App\Feeds\Items\UserFeedItem;
use App\Models\User;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class UserFeed extends Feed
{
    public function builder(): Builder
    {
        return User::query()
            ->whereNotNull('email_verified_at')
            ->where('created_at', '>', now()->subYear());
    }

    public function item(Model $model): FeedItem
    {
        return new UserFeedItem($model);
    }
}
```

## Jedes Element definieren {/* #define-each-item */}

```php source="docs/snippets/generation-feed-item.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

/** @property-read \App\Models\User $model */
class UserFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name'  => $this->model->name,
            'email' => $this->model->email,
        ];
    }
}
```

## Datei erzeugen {/* #generate-the-file */}

```bash
php artisan feed:generate
```

Der Befehl gibt den erzeugten Pfad aus. Das Standardformat ist XML und der Standard-Datenträger ist `public`; beides kann in der Feed-Klasse oder der Paketkonfiguration geändert werden.
