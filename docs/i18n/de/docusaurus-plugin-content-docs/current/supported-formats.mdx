# Unterstützte Formate

- **xml** — Erzeugt Feeds im XML-Format.
- **json** — Erzeugt Feeds im JSON-Format.
- **jsonl** — Erzeugt Feeds im JSON-Lines-Format.
- **csv** — Erzeugt Feeds im CSV-Format.
- **rss** — Erzeugt Feeds im RSS-Atom-Format.

Standardmäßig wird das Format `xml` verwendet.

## Konverteroptionen pro Feed {/* #converter-options */}

Wenden Sie `DragonCode\LaravelFeed\Attributes\Config` auf eine Feed-Klasse an, um deren Konvertereinstellungen zu überschreiben:

```php
use App\Models\User;
use DragonCode\LaravelFeed\Attributes\Config;
use DragonCode\LaravelFeed\Enums\FeedFormatEnum;
use DragonCode\LaravelFeed\Feeds\Feed;
use Illuminate\Database\Eloquent\Builder;

#[Config('delimiter', ',')]
#[Config('enclosure', "'")]
#[Config('lineEnding', "\r\n")]
class UserFeed extends Feed
{
    protected FeedFormatEnum $format = FeedFormatEnum::Csv;

    public function builder(): Builder
    {
        return User::query();
    }
}
```

Wiederholen Sie das Attribut für jede Einstellung. Wird ein Name innerhalb derselben Klasse mehrfach angegeben, gilt das zuletzt deklarierte Attribut.

Die Einstellungsnamen sind Parameternamen des Konverterkonstruktors. Nur angegebene Werte überschreiben die Anwendungskonfiguration; andere Einstellungen behalten ihre konfigurierten Werte. `lineEnding` entspricht `feeds.converters.csv.line_ending`.

| Format | Unterstützte Schlüssel |
| --- | --- |
| `csv` | `delimiter`, `enclosure`, `escape`, `lineEnding` |
| `json` | `options`, `pretty` |
| `jsonl` | `options` |
| `xml`, `rss` | `pretty` |

Optionen des übergeordneten Feeds werden vererbt, und Schlüssel des untergeordneten Feeds überschreiben übergeordnete Schlüssel. Verwenden Sie nur Schlüssel, die das gewählte Format unterstützt; nicht unterstützte Schlüssel lösen `InvalidArgumentException` aus. Das Attribut ändert weder die Anwendungskonfiguration noch andere Feeds.

JSON Lines schreibt immer ein Element pro Zeile, und `JSON_PRETTY_PRINT` wird aus `options` entfernt. Benutzerdefinierte Container-Bindings müssen die angegebenen Konstruktorparameter berücksichtigen.
