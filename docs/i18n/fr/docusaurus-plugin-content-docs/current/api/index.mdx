## Points d’extension {/* #extension-points */}

- Étendez `Feed` ou un préréglage pour définir la source de données et le contrat de sortie.
- Étendez `FeedItem` et `FeedInfo` pour contrôler les données sérialisées.
- Implémentez `DragonCode\LaravelFeed\Contracts\Transformer` pour une conversion scalaire personnalisée.
- Renvoyez `DragonCode\LaravelFeed\Data\OptionalData` lorsqu’un champ doit être omis.
- Enregistrez des macros sur `Feed`, `FeedItem` ou `FeedInfo` pour les utilitaires de l’application.
