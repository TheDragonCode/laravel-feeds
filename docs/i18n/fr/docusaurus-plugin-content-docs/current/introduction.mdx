# Bien démarrer

<PageLead>
Installez le paquet, définissez une requête Eloquent et la structure d’un élément, puis générez un fichier de flux. Dans une application Laravel existante, le premier export fonctionnel prend environ cinq minutes.
</PageLead>

## Prérequis {/* #prerequisites */}

- PHP `8.2` ou une version `8.x` ultérieure acceptée par Composer
- Laravel `11.x`, `12.x` ou `13.x`
- Une base de données et un disque de système de fichiers configurés

## Installer et préparer {/* #install-and-prepare */}

```bash
composer require dragon-code/laravel-feeds
php artisan vendor:publish --tag="feeds"
php artisan migrate
php artisan make:feed User --item
```

Le générateur crée les classes du flux et de l’élément. Il crée aussi la modification de base de données qui enregistre le flux. Exécutez cette migration avant la première génération si elle a été créée après la commande `migrate` précédente.

## Définir la source de données {/* #define-the-data-source */}

Renvoyez un builder Eloquent afin de lire les enregistrements par lots.

```php source="docs/snippets/create-feeds-feed.php" lines="5-"
namespace App\Feeds;

use App\Feeds\Items\UserFeedItem;
use App\Models\User;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class UserFeed extends Feed
{
    public function builder(): Builder
    {
        return User::query()
            ->whereNotNull('email_verified_at')
            ->where('created_at', '>', now()->subYear());
    }

    public function item(Model $model): FeedItem
    {
        return new UserFeedItem($model);
    }
}
```

## Définir chaque élément {/* #define-each-item */}

```php source="docs/snippets/generation-feed-item.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

/** @property-read \App\Models\User $model */
class UserFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name'  => $this->model->name,
            'email' => $this->model->email,
        ];
    }
}
```

## Générer le fichier {/* #generate-the-file */}

```bash
php artisan feed:generate
```

La commande affiche le chemin généré. Le format par défaut est XML et le disque par défaut est `public` ; vous pouvez modifier les deux dans la classe du flux ou la configuration du paquet.
