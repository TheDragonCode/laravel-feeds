# Formats pris en charge

- **xml** — Génère des flux au format XML.
- **json** — Génère des flux au format JSON.
- **jsonl** — Génère des flux au format JSON Lines.
- **csv** — Génère des flux au format CSV.
- **rss** — Génère des flux au format RSS Atom.

Le format `xml` est utilisé par défaut.
