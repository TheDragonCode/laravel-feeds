# Guide de contribution

Les contributions sont les **bienvenues** et seront pleinement **créditées**.

Nous acceptons les contributions sous forme de Pull Requests sur [tous les projets](https://github.com/TheDragonCode) de notre organisation.

## Style du code {/* #code_style */}

**Laravel Feeds** respecte la norme de codage [PER-3](https://www.php-fig.org/per/coding-style/) et la norme de chargement automatique [PSR-4](https://www.php-fig.org/psr/psr-4/).

Pour appliquer le formatage du code, exécutez la commande suivante :

```bash
composer style
```

## Code de conduite {/* #code_of_conduct */}

Le code de conduite de Laravel est issu du code de conduite [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Toute infraction peut être signalée à [Andrey Helldar](mailto:helldar@dragon-code.pro) :

- Les participants doivent faire preuve de tolérance envers les opinions divergentes.
- Les participants doivent veiller à ce que leurs propos et leurs actes soient exempts d’attaques personnelles et de remarques dénigrantes.
- Lorsqu’ils interprètent les paroles et les actes d’autrui, les participants doivent toujours présumer de bonnes intentions.
- Aucun comportement pouvant raisonnablement être considéré comme du harcèlement ne sera toléré.
