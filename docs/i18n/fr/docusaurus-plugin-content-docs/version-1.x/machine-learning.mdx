# Apprentissage automatique

Vous pouvez aider votre LLM à mieux comprendre la structure et les conventions de ce projet.

Pour cela, importez les instructions du fichier suivant : [**llms.txt**](https://feeds.dragon-code.pro/llms.txt).

Ce fichier est un document Markdown unique et consolidé qui contient l’ensemble de la documentation compilée du projet. Il est conçu comme une base de connaissances pour les LLM, par exemple comme pièce jointe à un prompt système, corpus de recherche ou fichier de connaissances personnalisé.

:::note
Enregistrez l’URL et réimportez régulièrement le fichier pour récupérer les mises à jour du projet.
:::
