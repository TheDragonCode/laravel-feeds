# 기여 가이드

기여는 언제나 **환영**하며 기여자에게 충분히 **감사 표시**를 합니다.

우리 조직의 [모든 프로젝트](https://github.com/TheDragonCode)는 Pull Request를 통한 기여를 받습니다.

## 코드 스타일 {/* #code_style */}

**Laravel Feeds**는 [PER-3](https://www.php-fig.org/per/coding-style/) 코딩 표준과 [PSR-4](https://www.php-fig.org/psr/psr-4/) 오토로딩 표준을 따릅니다.

코드 스타일 서식을 적용하려면 다음 콘솔 명령을 실행하십시오.

```bash
composer style
```

## 행동 강령 {/* #code_of_conduct */}

Laravel 행동 강령은 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 행동 강령을 바탕으로 합니다. 행동 강령 위반은 [Andrey Helldar](mailto:helldar@dragon-code.pro)에게 신고할 수 있습니다.

- 참여자는 반대 의견을 존중해야 합니다.
- 참여자는 말과 행동에 인신공격이나 비하 발언이 포함되지 않도록 해야 합니다.
- 다른 사람의 말과 행동을 해석할 때는 항상 선의를 전제로 해야 합니다.
- 합리적으로 괴롭힘으로 볼 수 있는 행동은 허용되지 않습니다.
