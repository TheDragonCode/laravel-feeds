# 지원 형식

- **xml** — XML 형식으로 피드를 생성합니다.
- **json** — JSON 형식으로 피드를 생성합니다.
- **jsonl** — JSON Lines 형식으로 피드를 생성합니다.
- **csv** — CSV 형식으로 피드를 생성합니다.
- **rss** — RSS Atom 형식으로 피드를 생성합니다.

기본값은 `xml` 형식입니다.
