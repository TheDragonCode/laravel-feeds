# 머신 러닝

LLM이 이 프로젝트의 구조와 규칙을 더 잘 이해하도록 할 수 있습니다.

이를 위해 다음 파일의 지침을 가져오십시오: [**llms.txt**](https://feeds.dragon-code.pro/llms.txt).

이 파일은 프로젝트의 컴파일된 문서를 담은 하나의 통합 Markdown 문서입니다. LLM의 지식 베이스로 사용하도록 설계되었습니다. 예를 들어 시스템 프롬프트 첨부 파일, 검색 코퍼스 또는 사용자 지정 지식 파일로 사용할 수 있습니다.

:::note
URL을 저장하고 프로젝트 변경 사항을 반영할 수 있도록 주기적으로 다시 가져오십시오.
:::
