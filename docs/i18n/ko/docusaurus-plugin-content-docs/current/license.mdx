저작권 (c) 2025-2026 Andrey Helldar

이 소프트웨어 및 관련 문서 파일(이하 “소프트웨어”)의 사본을 취득하는 모든 사람에게 소프트웨어를 제한 없이 취급할 수 있는 권한을 무상으로 부여합니다. 여기에는 소프트웨어 사본을 사용, 복사, 수정, 병합, 게시, 배포, 재라이선스 및/또는 판매할 권리와 소프트웨어를 제공받은 사람에게 이를 허용할 권리가 제한 없이 포함되며, 다음 조건을 따릅니다.
