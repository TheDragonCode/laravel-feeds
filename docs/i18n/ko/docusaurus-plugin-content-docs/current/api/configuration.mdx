# 구성 참조

<PageLead>
`php artisan vendor:publish --tag="feeds"`로 `config/feeds.php`를 게시하십시오. 환경 값은 Laravel이 구성 캐시를 만들 때 읽습니다.
</PageLead>

## 기본 설정 {/* #core-settings */}

| 키 | 기본값 | 용도 |
| --- | --- | --- |
| `model` | `DragonCode\LaravelFeed\Models\Feed` | 피드 등록에 사용하는 Eloquent 모델입니다. 대체 모델은 패키지 모델을 확장해야 합니다. |
| `pretty` | `false` | 형식화된 XML 및 JSON 출력을 활성화합니다. |
| `date.format` | `DATE_ATOM` | 날짜 트랜스포머가 사용하는 PHP 날짜 형식입니다. |
| `date.timezone` | `UTC` | 날짜 직렬화에 사용하는 시간대입니다. |
| `table.connection` | `DB_CONNECTION`, 다음 `sqlite` | 피드 등록용 데이터베이스 연결입니다. |
| `table.table` | `feeds` | 피드 등록 테이블 이름입니다. |

## 스케줄 및 큐 {/* #scheduling-and-queues */}

| 환경 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `FEED_SCHEDULE_TTL` | `1440` | 스케줄 잠금 수명(분)입니다. |
| `FEED_SCHEDULE_RUN_BACKGROUND` | `true` | 예약된 피드 명령을 백그라운드에서 실행합니다. |
| `FEED_QUEUE_ENABLED` | `false` | Laravel Queue로 생성을 전달합니다. |
| `FEED_QUEUE_CONNECTION` | `QUEUE_CONNECTION`, 다음 `database` | 피드 작업용 큐 연결입니다. |
| `FEED_QUEUE_NAME` | 연결 기본값 | 큐 이름입니다. |
| `FEED_QUEUE_UNIQUE_TTL` | `3600` | 고유 작업 잠금 수명(초)입니다. |
| `FEED_CONSOLE_PROGRESS_BAR_ENABLED` | `false` | 콘솔 진행률 표시줄을 표시합니다. |

비동기 연결에서 큐 모드를 사용하려면 워커가 필요합니다. `sync` 연결은 명령 프로세스에서 생성을 실행합니다.

## 트랜스포머 {/* #transformers */}

기본 파이프라인에는 `BoolTransformer`, `DateTimeTransformer`, `EnumTransformer`가 이 순서로 포함됩니다. 조건에 맞는 각 트랜스포머는 이전 트랜스포머가 반환한 값을 받습니다.

`DragonCode\LaravelFeed\Contracts\Transformer`를 구현한 후 사용자 지정 클래스를 `transformers`에 추가하십시오. Laravel은 서비스 컨테이너를 통해 클래스를 해석합니다.

## 변환기 설정 {/* #converter-settings */}

| 키 | 기본값 |
| --- | --- |
| `converters.json.options` | `JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE` |
| `converters.jsonl.options` | `JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE` |
| `converters.csv.delimiter` | `;` |
| `converters.csv.enclosure` | `"` |
| `converters.csv.escape` | 빈 문자열 |
| `converters.csv.line_ending` | `PHP_EOL` |
