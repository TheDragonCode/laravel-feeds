# API 참조

<PageLead>
워크플로를 이미 알고 있고 정확한 클래스, 메서드, 구성 키, 이벤트 또는 오류 계약이 필요할 때 이 섹션을 사용하십시오.
</PageLead>

## 확장 지점 {/* #extension-points */}

- 데이터 소스와 출력 계약을 정의하려면 `Feed` 또는 프리셋을 확장하십시오.
- 직렬화할 데이터를 제어하려면 `FeedItem`과 `FeedInfo`를 확장하십시오.
- 사용자 지정 스칼라 변환에는 `DragonCode\LaravelFeed\Contracts\Transformer`를 구현하십시오.
- 필드를 생략해야 할 때 `DragonCode\LaravelFeed\Data\OptionalData`를 반환하십시오.
- 애플리케이션 도우미를 위해 `Feed`, `FeedItem` 또는 `FeedInfo`에 매크로를 등록하십시오.
