# 등록된 피드 목록 조회 {/* #list_feeds */}

버전 2.1.0부터 파일을 생성하거나 상태를 변경하지 않고 피드 등록 목록을 조회할 수 있습니다.

```bash
php artisan feed:list
```

이 명령에는 별도의 인수나 옵션이 없습니다. 비활성 피드와 소프트 삭제된 피드를 포함한 모든 등록 정보를 표로 표시합니다.

| 열 | 의미 |
| --- | --- |
| `id` | 등록 ID. |
| `slug` | `feed:generate`에서 사용하는 등록 slug. |
| `title` | 등록 제목. |
| `expression` | 저장된 cron 표현식. |
| `next_run` | UTC 오프셋이 포함된 ISO 8601 형식의 다음 cron 실행 시각. 가능한 시각이 없으면 JSON에서는 `null`. |
| `is_active` | 등록 정보의 활성화 여부. |
| `is_deleted` | 등록 정보의 소프트 삭제 여부. |
| `last_activity` | ISO 8601 형식으로 기록된 마지막 생성 시각. 설정되지 않은 경우 JSON에서는 `null`. |

삭제되지 않은 등록 정보가 먼저 표시되고 소프트 삭제된 등록 정보가 뒤에 표시됩니다. 각 그룹에서는 활성 피드가 먼저 표시되며, 이어서 제목과 ID순으로 정렬됩니다. 콘솔에서 불리언 값은 `true` 또는 `false`로 표시됩니다.

`next_run`은 `app.schedule_timezone`을 사용하며, 설정되지 않은 경우 `app.timezone`을 사용합니다. 형식은 `YYYY-MM-DDTHH:mm:ss±HH:mm`이며, 예시는 `2025-09-04T09:00:00-04:00`입니다. 비활성 또는 소프트 삭제된 등록 정보에도 저장된 cron 표현식의 다음 실행 시각을 표시하지만 피드 실행을 보장하지는 않습니다. `0 0 31 2 *`처럼 가능한 실행 날짜가 없는 표현식은 JSON에서 `null`로, 콘솔에서는 빈 셀로 표시됩니다.

삭제되지 않은 등록 정보의 slug를 사용하여 해당 피드를 생성하십시오.

```bash
php artisan feed:generate products
```

등록 정보가 없으면 콘솔에 `No feeds available`이 표시됩니다.

## AI 에이전트의 목록 조회 {/* #list_feeds_agent */}

인식된 AI 코딩 에이전트 안에서 `feed:list`는 한 줄로 된 압축 JSON 객체 하나를 자동으로 반환합니다. 추가 옵션은 필요하지 않습니다. 불리언 필드는 JSON 불리언으로 유지됩니다.

```json
{
  "tool": "feed:list",
  "result": "success",
  "feeds": [
    {
      "id": 1,
      "slug": "products",
      "title": "Products",
      "expression": "0 * * * *",
      "next_run": "2025-09-04T05:00:00+00:00",
      "is_active": true,
      "is_deleted": false,
      "last_activity": null
    }
  ]
}
```

위 예제는 읽기 쉽도록 형식을 지정했습니다. 목록이 비어 있으면 같은 래퍼에 `"feeds": []`를 반환합니다.
