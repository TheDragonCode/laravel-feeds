# 피드 및 데이터

<PageLead>
핵심 API는 데이터 소스, 항목 매핑, 피드 수준 메타데이터, 출력 구조 및 생성 결과를 분리합니다.
</PageLead>

## Feed {/* #feed */}

`DragonCode\LaravelFeed\Feeds\Feed`는 내보내기의 기본 클래스입니다. `builder()`를 구현하고 피드에 필요한 출력 지점만 재정의하십시오.

<ApiSignature>abstract public function builder(): Builder</ApiSignature>

| 메서드 | 기본값 | 계약 |
| --- | --- | --- |
| `builder(): Builder` | 추상 메서드 | 데이터 소스로 사용할 Eloquent 쿼리를 반환합니다. |
| `item(Model $model): FeedItem` | 새 기본 `FeedItem` | 하나의 모델을 출력 항목으로 매핑합니다. |
| `transformers(): array` | `[]` | 이 피드의 트랜스포머 클래스 이름을 앞에 추가합니다. |
| `chunkSize(): int` | `1000` | 데이터베이스 쿼리 청크 크기입니다. |
| `perFile(): int` | `0` | 파일당 레코드 수입니다. 0이면 개수에 따른 분할을 끕니다. |
| `maxFiles(): int` | `0` | 최대 출력 파일 수입니다. 0이면 제한이 없습니다. |
| `header(): string` | XML/RSS용 XML 선언 | 루트와 항목 앞에 기록할 내용입니다. |
| `footer(): string` | 빈 문자열 | 루트와 항목 뒤에 기록할 내용입니다. |
| `root(): ElementData` | 클래스에서 파생한 요소 이름 | 루트 요소와 속성을 정의합니다. |
| `info(): FeedInfo` | 빈 `FeedInfo` | 피드 수준 정보를 정의합니다. |
| `filename(): string` | 클래스에서 파생한 파일 이름 | 디스크 기준 출력 파일 이름을 반환합니다. |
| `path($suffix): string` | 어댑터가 해석한 경로 | 로컬 또는 어댑터가 해석한 경로를 반환합니다. |
| `storagePath($suffix): string` | 디스크 기준 파일 이름 | 저장소 작업에 사용할 경로를 반환합니다. |
| `storage(): FilesystemAdapter` | `public` 디스크 | Laravel 파일시스템 디스크를 해석하고 검증합니다. |
| `format(): FeedFormatEnum` | `Xml` | 구성된 출력 형식을 반환합니다. |
| `converterOptions(): array` | `[]` | 이 피드가 상속한 `Config` 속성 값을 반환합니다. 자식 키는 부모 키를 재정의합니다. |

`Feed`는 Laravel의 `Conditionable`과 `Macroable`을 사용합니다.

## 피드 대상 {/* #feed-targets */}

`DragonCode\LaravelFeed\Feeds\FeedTarget`은 독립적으로 생성되는 하나의 출력을 식별합니다. 생성자는 비어 있지 않은 문자열 키와 선택적인 매개변수 배열을 받습니다.

<ApiSignature>public function __construct(public readonly string $key, public readonly array $parameters = [])</ApiSignature>

선택적으로 사용하는 피드 클래스에 `DragonCode\LaravelFeed\Contracts\HasFeedTargets`를 구현하십시오. 선택 사항인 `DragonCode\LaravelFeed\Concerns\InteractsWithFeedTargets` 트레이트는 `forTarget()`과 `target()`을 구현하며, 피드 클래스는 대상 검색을 구현합니다.

| 메서드 | 계약 |
| --- | --- |
| `targets(): iterable` | 전체 명령 및 스케줄 실행에 사용할 모든 `FeedTarget`을 지연 방식으로 반환합니다. |
| `findTarget(string $key): ?FeedTarget` | 명시적인 명령 대상을 같은 키로 직접 해석하거나 `null`을 반환합니다. |
| `forTarget(FeedTarget $target): static` | 설정된 복제본을 반환하고 캐시된 파일 이름을 초기화합니다. |
| `target(): FeedTarget` | 설정된 대상을 반환하며, 설정되지 않았으면 `LogicException`을 발생시킵니다. |

생성자는 비어 있거나 공백만 있는 키를 거부하지만 다른 값은 정규화하거나 정제하지 않습니다. 대상 매개변수는 패키지에 불투명하며 큐 작업의 스냅샷으로 직렬화됩니다. 키는 대상의 식별자이므로 피드 클래스 안에서 안정적이고 고유해야 합니다. [별도 출력 파일 설정](../feed-targets.mdx)과 [명령에서 출력 선택](../generation.mdx#target_selection)을 참조하십시오.

## FeedItem 및 FeedInfo {/* #feed-item-and-feed-info */}

`FeedItem`은 현재 Eloquent 모델을 받습니다. 기본 동작은 다음과 같습니다.

- `name()`은 모델 클래스 기본 이름을 kebab case로 반환합니다.
- `attributes()`는 빈 배열을 반환합니다.
- `toArray()`는 모델 배열을 반환합니다.

`FeedInfo::toArray()`는 빈 배열을 반환합니다. 두 클래스 모두 `Conditionable`과 `Macroable`을 사용합니다. 출력에 명시적인 스키마가 필요하면 확장하십시오.

### 항목의 날짜 형식 {/* #date-format */}

`DragonCode\LaravelFeed\Attributes\DateFormat`의 `#[DateFormat('Y-m-d H:i')]`를 `FeedItem` 클래스에 적용하여 날짜 형식을 재정의하십시오.

모델에 날짜 캐스트를 설정하고 `toArray()`에서 원래 `DateTimeInterface` 값을 반환하십시오. 이미 형식이 지정된 문자열은 다시 변환하지 않습니다.

```php
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Attributes\DateFormat;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

#[DateFormat('Y-m-d H:i')]
class ProductFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'finishedAt' => $this->model->finished_at,
            'createdAt' => $this->model->created_at,
            'updatedAt' => $this->model->updated_at,
        ];
    }
}
```

이 속성은 모든 출력 형식에 적용됩니다. 중첩된 JSON/XML 구조의 날짜와 XML/RSS 항목 속성을 위해 `attributes()`가 반환하는 날짜도 포함됩니다.

이 속성이 적용된 가장 가까운 부모 클래스의 형식을 상속합니다. 자식 클래스에 속성을 적용하면 상속된 형식을 재정의합니다. 이 속성은 피드별 날짜 형식과 전역 날짜 형식보다 우선하며 `feeds.date.timezone` 설정은 유지합니다.

`FeedInfo`, 루트 속성 및 이 속성이 없는 다른 항목은 일반적인 설정에 따른 변환 과정을 계속 사용합니다.

## ElementData {/* #element-data */}

`ElementData`는 세 가지 생성자 속성을 가진 읽기 전용 객체입니다.

| 속성 | 타입 | 기본값 |
| --- | --- | --- |
| `name` | `?string` | `null` |
| `attributes` | `array` | `[]` |
| `beforeInfo` | `bool` | `true` |

루트 요소를 생략하려면 `name`을 `null` 또는 빈 문자열로 설정하십시오. 피드 정보를 루트 앞에 쓰려면 `beforeInfo`를 `false`로 설정하십시오.

## 생성 결과 {/* #generation-result */}

`GeneratorService::feed()`는 `GenerationResultData`를 반환합니다. 읽기 전용 `paths` 속성에는 게시된 파일이 출력 순서대로 들어 있습니다. `records`는 각 경로를 해당 파일에 기록된 레코드 수와 연결합니다.

프로그래밍 방식의 생성 및 등록 메서드는 [런타임 서비스 및 계약](./runtime.mdx)에 정리되어 있습니다.
