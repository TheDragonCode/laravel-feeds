# Падзеі і выключэнні

<PageLead>
Выкарыстоўвайце падзеі жыццёвага цыкла для інтэграцыі з праграмай, а тыпы выключэнняў — для аднаўлення на мяжы, якая можа апрацаваць памылку.
</PageLead>

## Падзеі жыццёвага цыкла {/* #lifecycle-events */}

| Падзея | Публічныя даныя | Момант адпраўкі |
| --- | --- | --- |
| `FeedStartingEvent` | `feed`, `target` | Пасля папярэдняй праверкі сховішча і шляху, перад вызначэннем канвертара і падрыхтоўкай файлаў. |
| `FeedFinishedEvent` | `feed`, `target`, `path`, `paths` | Пасля паспяховай публікацыі ўсіх згенераваных файлаў. |

`$target` змяшчае ключ мэты для мэтавай генерацыі і `null` для звычайнай стужкі. `FeedFinishedEvent::$paths` змяшчае ўсе апублікаваныя шляхі па парадку. `$path` захавана для сумяшчальнасці і заўсёды змяшчае першы шлях.

## Памылкі ўводу і пошуку {/* #input-and-lookup-failures */}

| Выключэнне | Значэнне |
| --- | --- |
| `InvalidFeedArgumentException` | Ідэнтыфікатар стужкі ў кансолі няправільны. |
| `FeedNotFoundException` | Рэгістрацыя з запытаным ідэнтыфікатарам не існуе. |
| `InvalidExpressionException` | Выраз раскладу няправільны. |
| `UnknownFeedClassException` | Наладжаны клас стужкі немагчыма атрымаць. |
| `UnexpectedClassException` | Атрыманы клас не адпавядае чаканаму кантракту. |

Выбар мэты выкарыстоўвае выключэнні SPL. `feed:generate --target` кідае `InvalidArgumentException`, калі адсутнічае ідэнтыфікатар стужкі або ключ, ключ пусты ці стужка не рэалізуе `HasFeedTargets`. Метад кідае `UnexpectedValueException`, калі `findTarget()` вяртае `null`.

## Памылкі серыялізацыі і сховішча {/* #serialization-and-storage-failures */}

| Выключэнне | Значэнне |
| --- | --- |
| `InvalidCsvRowException` | Радок CSV не адпавядае вызначанай схеме слупкоў. |
| `InvalidCsvValueException` | Поле CSV немагчыма серыялізаваць як скалярнае значэнне. |
| `InvalidXmlCDataException` | Значэнне CDATA няправільнае. |
| `InvalidXmlFragmentException` | Неапрацаваны фрагмент XML няправільны. |
| `UnsupportedStorageDiskException` | Выбраны дыск Laravel не пераўтвараецца ў `FilesystemAdapter`. |
| `OpenFeedException` | Немагчыма адкрыць чарнавы рэсурс вываду. |
| `WriteFeedException` | Немагчыма цалкам запісаць вывад. |
| `CloseFeedException` | Немагчыма закрыць рэсурс вываду. |
| `ResourceMetaException` | Абавязковыя метаданыя патоку недаступныя. |
| `FeedGenerationException` | Генерацыя пэўнага класа стужкі завяршылася памылкай. |

`FeedGenerationException::getFeed()` вяртае клас стужкі. `getFeedTarget()` вяртае ключ мэты для мэтавай генерацыі і `null` для звычайнай стужкі. Зыходная памылка застаецца даступнай праз `getPrevious()`.

Перахоплівайце выключэнні толькі там, дзе праграма можа дадаць аднаўленне або зразумелы карыстальніку кантэкст. Невыпраўляльныя памылкі генерацыі павінен паведамляць Laravel.
