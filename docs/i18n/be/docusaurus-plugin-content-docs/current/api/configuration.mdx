# Даведнік па канфігурацыі

<PageLead>
Апублікуйце `config/feeds.php` камандай `php artisan vendor:publish --tag="feeds"`. Значэнні асяроддзя чытаюцца падчас стварэння кэша канфігурацыі Laravel.
</PageLead>

## Асноўныя налады {/* #core-settings */}

| Ключ | Стандартнае значэнне | Прызначэнне |
| --- | --- | --- |
| `model` | `DragonCode\LaravelFeed\Models\Feed` | Мадэль Eloquent для рэгістрацый стужак. Замена павінна пашыраць мадэль пакета. |
| `pretty` / `FEED_PRETTY` | `false` | Уключае фарматаваны вывад XML і JSON. |
| `date.format` | `DATE_ATOM` | Фармат даты PHP для пераўтваральніка дат. |
| `date.timezone` / `FEED_TIMEZONE` | `UTC` | Часавы пояс пры серыялізацыі дат. |
| `table.connection` | `DB_CONNECTION`, затым `sqlite` | Падключэнне да базы даных для рэгістрацый стужак. |
| `table.table` / `FEED_TABLE` | `feeds` | Імя табліцы рэгістрацый стужак. |

## Расклад і чэргі {/* #scheduling-and-queues */}

| Зменная асяроддзя | Стандартнае значэнне | Прызначэнне |
| --- | --- | --- |
| `FEED_SCHEDULE_TTL` | `1440` | Час жыцця блакіроўкі раскладу ў хвілінах. |
| `FEED_SCHEDULE_RUN_BACKGROUND` | `true` | Запускае запланаваныя каманды стужак у фоне. |
| `FEED_QUEUE_ENABLED` | `false` | Адпраўляе генерацыю праз Laravel Queue. |
| `FEED_QUEUE_CONNECTION` | `QUEUE_CONNECTION`, затым `database` | Падключэнне чаргі для задач стужак. |
| `FEED_QUEUE_NAME` | Стандартная чарга падключэння | Імя чаргі. |
| `FEED_QUEUE_UNIQUE_TTL` | `3600` | Час жыцця блакіроўкі ўнікальнай задачы ў секундах. |
| `FEED_CONSOLE_PROGRESS_BAR_ENABLED` | `false` | Паказвае індыкатар прагрэсу ў кансолі. |

Для асінхроннага падключэння рэжым чаргі патрабуе апрацоўшчык. Падключэнне `sync` па-ранейшаму выконвае генерацыю ў працэсе каманды.

## Пераўтваральнікі {/* #transformers */}

Стандартны канвеер змяшчае `BoolTransformer`, `DateTimeTransformer` і `EnumTransformer` у такім парадку. Кожны адпаведны пераўтваральнік атрымлівае значэнне, вернутае папярэднім.

Пасля рэалізацыі `DragonCode\LaravelFeed\Contracts\Transformer` дадайце карыстальніцкі клас у `transformers`. Laravel атрымае яго праз кантэйнер сэрвісаў.

## Налады канвертараў {/* #converter-settings */}

| Ключ | Стандартнае значэнне |
| --- | --- |
| `converters.json.options` | `JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE` |
| `converters.jsonl.options` | `JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE` |
| `converters.csv.delimiter` | `;` |
| `converters.csv.enclosure` | `"` |
| `converters.csv.escape` | Пусты радок |
| `converters.csv.line_ending` | `PHP_EOL` |
