## Пункты пашырэння {/* #extension-points */}

- Пашырце `Feed` або перадусталёўку, каб вызначыць крыніцу даных і кантракт вываду.
- Пашырце `FeedItem` і `FeedInfo`, каб кіраваць серыялізаванымі данымі.
- Рэалізуйце `DragonCode\LaravelFeed\Contracts\Transformer` для карыстальніцкага пераўтварэння скалярных значэнняў.
- Вяртайце `DragonCode\LaravelFeed\Data\OptionalData`, калі поле трэба прапусціць.
- Рэгіструйце макрасы ў `Feed`, `FeedItem` або `FeedInfo` для дапаможных метадаў праграмы.
