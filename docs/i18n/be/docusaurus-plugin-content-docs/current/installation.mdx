# Усталяванне і наладжванне

Пакет можна ўсталяваць праз [Composer](https://getcomposer.org):

```bash
composer require dragon-code/laravel-feeds
```

Апублікуйце [міграцыю](https://github.com/TheDragonCode/laravel-feeds/blob/main/database/migrations/2025_09_01_231655_create_feeds_table.php) і файл канфігурацыі [config/feeds.php](https://github.com/TheDragonCode/laravel-feeds/blob/main/config/feeds.php) наступнай камандай:

```bash
php artisan vendor:publish --tag="feeds"
```

:::warning
**Перад запускам міграцый** праверце налады падключэння да базы даных у файле `config/feeds.php`.
:::

Цяпер можна запусціць міграцыі і перайсці да [стварэння стужак](./create-feeds.mdx).

```bash
php artisan migrate
```

Пры абнаўленні існуючай устаноўкі скапіруйце з пакета толькі `database/migrations/2026_10_14_000000_add_slug_to_feeds_table.php` у каталог міграцый прыкладання. Задайце timestamp імя файла адразу пасля фактычнай міграцыі `create_feeds_table` прыкладання і перад усімі міграцыямі рэгістрацыі стужак; захавайце суфікс `add_slug_to_feeds_table`. Затым выканайце `php artisan migrate`. Міграцыя выкарыстоўвае наладжаныя падключэнне і табліцу і запаўняе slug з існуючых назваў, уключаючы мякка выдаленыя запісы. Не публікуйце паўторна і не запускайце зыходную міграцыю стварэння табліцы. Замяніце лікавыя ідэнтыфікатары стужак у камандах і ручных раскладах захаванымі slug.
