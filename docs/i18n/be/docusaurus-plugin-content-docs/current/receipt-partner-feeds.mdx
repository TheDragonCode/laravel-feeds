# Адзін файл стужкі для кожнага партнёра

Гэты рэцэпт рэгіструе адну стужку `PartnerFeed` і генеруе асобны адфільтраваны XML-файл для кожнага партнёра. Напрыклад:

```text
storage/app/public/partners/42.xml
storage/app/public/partners/81.xml
```

## Стварыце стужку {/* #create-feed */}

```bash
php artisan make:feed Partner
```

## Наладзьце вынікі для партнёраў {/* #configure-partner-outputs */}

Замяніце згенераваны клас стужкі наступным:

```php source="docs/snippets/targeted-feed.php"
<?php

declare(strict_types=1);

namespace App\Feeds;

use App\Models\Partner;
use App\Models\Product;
use DragonCode\LaravelFeed\Concerns\InteractsWithFeedTargets;
use DragonCode\LaravelFeed\Contracts\HasFeedTargets;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\FeedTarget;
use Illuminate\Database\Eloquent\Builder;

class PartnerFeed extends Feed implements HasFeedTargets
{
    use InteractsWithFeedTargets;

    public function targets(): iterable
    {
        foreach (Partner::query()->select('id')->lazyById() as $partner) {
            yield $this->makeTarget($partner);
        }
    }

    public function findTarget(string $key): ?FeedTarget
    {
        $partner = Partner::query()->find($key);

        if (! $partner || (string) $partner->getKey() !== $key) {
            return null;
        }

        return $this->makeTarget($partner);
    }

    public function builder(): Builder
    {
        return Product::query()->where(
            'partner_id',
            $this->target()->parameters['partner_id'],
        );
    }

    public function filename(): string
    {
        return "partners/{$this->target()->key}.xml";
    }

    private function makeTarget(Partner $partner): FeedTarget
    {
        return new FeedTarget(
            key       : (string) $partner->getKey(),
            parameters: ['partner_id' => $partner->getKey()],
        );
    }
}
```

`targets()` ляніва пералічвае партнёраў для поўнага запуску. `findTarget()` вызначае яўна запытаныя ключы без загрузкі ўсіх партнёраў. `builder()` фільтруе тавары для актыўнага партнёра, а `filename()` задае ўнікальны шлях для кожнага партнёра.

## Актывуйце {/* #activate */}

Праверце згенераваны файл [аперацыі або міграцыі](./create-feeds.mdx), а затым выканайце адпаведную каманду:

```bash
# For Laravel Deploy Operations
php artisan operations

# For Laravel Migrations
php artisan migrate
```

## Згенеруйце файлы ўсіх партнёраў {/* #generate-all */}

Перадайце ідэнтыфікатар рэгістрацыі стужкі. Каманда згенеруе файлы для ўсіх партнёраў, вернутых `targets()`:

```bash
php artisan feed:generate 123
```

Для партнёраў `42` і `81` будуць згенераваны наступныя шляхі:

```text
storage/app/public/partners/42.xml
storage/app/public/partners/81.xml
```

## Згенеруйце файлы выбраных партнёраў {/* #generate-selected */}

Выкарыстоўвайце паўтаральны параметр `--target`, калі трэба абнавіць файлы толькі пэўных партнёраў:

```bash
php artisan feed:generate 123 --target=42
php artisan feed:generate 123 --target=42 --target=81
```

## Падзяліце вынік кожнага партнёра паводле колькасці запісаў {/* #split-each-output */}

Дадайце `perFile()`, калі вынік аднаго партнёра таксама можа стаць занадта вялікім:

```php
public function perFile(): int
{
    return 50000;
}
```

У такім выпадку партнёр `42` можа стварыць `partners/42-1.xml`, `partners/42-2.xml` і наступныя часткі. Гэты падзел паводле колькасці запісаў прымяняецца незалежна да кожнага партнёра.
