# Сумяшчальнасць

<PageLead>
Выкарыстоўвайце граф залежнасцей, вырашаны Composer, як канчатковую праверку сумяшчальнасці пэўнай праграмы.
</PageLead>

## Матрыца выканання {/* #runtime-matrix */}

<ResponsiveTable label="Сумяшчальнасць асяроддзя выканання Laravel Feeds">

| Кампанент | Падтрыманыя версіі |
| --- | --- |
| PHP | `8.2` і пазнейшыя версіі `8.x`, дазволеныя абмежаваннямі ўсталяванага пакета |
| Кампаненты Laravel | `11.x`, `12.x`, `13.x` |
| База даных | Любое падключэнне Laravel, падтрыманае наладжанай мадэллю Eloquent і міграцыяй |
| Файлавая сістэма | Даступныя для запісу дыскі Laravel, якія вяртаюць `FilesystemAdapter` |

</ResponsiveTable>

Усталяваны `composer.lock` — канчатковая крыніца для пэўнай праграмы. Composer адхіляе непадтрыманыя спалучэнні.

## Фарматы вываду {/* #output-formats */}

| Фармат | Пашырэнне | Укладзеныя даныя | Дырэктывы XML |
| --- | --- | --- | --- |
| XML | `.xml` | Так | Так |
| JSON | `.json` | Так | Не |
| JSON Lines | `.jsonl` | Адно значэнне JSON у радку | Не |
| CSV | `.csv` | Не; патрэбныя стабільныя скалярныя слупкі | Не |
| RSS | `.rss` | Так | Так |

## Неабавязковыя інтэграцыі {/* #optional-integrations */}

- Laravel Queue патрэбна толькі пры ўключаным рэжыме чаргі.
- Калі Laravel Deploy Operations усталяваны, яго выкарыстоўвае `make:feed`; інакш каманда стварае міграцыю.
- Неабавязковыя значэнні Spatie Laravel Data распазнаюцца, калі гэты пакет усталяваны.
