# Спіс зарэгістраваных стужак {/* #list_feeds */}

Пачынаючы з версіі 2.1.0, можна праглядаць рэгістрацыі стужак без генерацыі файлаў або змянення іх стану:

```bash
php artisan feed:list
```

Каманда не мае ўласных аргументаў або параметраў. Яна паказвае табліцу ўсіх рэгістрацый, у тым ліку неактыўных і мякка выдаленых стужак.

| Слупок | Значэнне |
| --- | --- |
| `id` | Ідэнтыфікатар рэгістрацыі. |
| `slug` | Slug рэгістрацыі, які выкарыстоўвае `feed:generate`. |
| `title` | Назва рэгістрацыі. |
| `expression` | Захаваны выраз cron. |
| `is_active` | Ці ўключана рэгістрацыя. |
| `is_deleted` | Ці мякка выдалена рэгістрацыя. |
| `last_activity` | Апошні запісаны час генерацыі ў фармаце ISO 8601; `null` у JSON, калі не зададзены. |

Спачатку паказваюцца нявыдаленыя рэгістрацыі, затым — мякка выдаленыя. У кожнай групе актыўныя стужкі ідуць першымі, далей радкі сартуюцца па назве і ідэнтыфікатары. Лагічныя значэнні ў кансолі паказваюцца як `true` або `false`.

Каб згенераваць стужку, выкарыстоўвайце slug нявыдаленай рэгістрацыі:

```bash
php artisan feed:generate products
```

Калі рэгістрацый няма, кансоль паказвае `No feeds available`.

## Спіс для ШІ-агента {/* #list_feeds_agent */}

Унутры распазнанага агента праграмавання са штучным інтэлектам `feed:list` аўтаматычна вяртае адзін кампактны аб'ект JSON у адзін радок. Дадатковы параметр не патрэбны. Лагічныя палі застаюцца лагічнымі значэннямі JSON:

```json
{
  "tool": "feed:list",
  "result": "success",
  "feeds": [
    {
      "id": 1,
      "slug": "products",
      "title": "Products",
      "expression": "0 * * * *",
      "is_active": true,
      "is_deleted": false,
      "last_activity": null
    }
  ]
}
```

Прыклад адфарматаваны для зручнасці чытання. Пусты спіс вяртаецца ў той жа абалонцы з `"feeds": []`.
