# Падзеі

Падчас выканання каманды стужкі адпраўляюць дзве падзеі:

- **`DragonCode\LaravelFeed\Events\FeedStartingEvent`** — падзея `FeedStartingEvent` адпраўляецца пасля папярэдняй праверкі сховішча і шляху, перад вызначэннем канвертара і падрыхтоўкай файлаў. Гэта не азначае, што чарнавы файл ужо існуе.
- **`DragonCode\LaravelFeed\Events\FeedFinishedEvent`** — падзея `FeedFinishedEvent` адпраўляецца пасля паспяховай публікацыі ўсіх згенераваных файлаў. Калі генерацыя завяршылася памылкай, гэта падзея не адпраўляецца.

Абедзве падзеі адкрываюць `$feed` з класам згенераванай стужкі і `$target` з ключом мэты або значэннем `null`. Для звычайнай стужкі `$target` мае значэнне `null`.

## Кантракт падзеі завяршэння {/* #finished_event_contract */}

Падзея завяршэння адкрывае наступныя публічныя ўласцівасці:

- `$paths` змяшчае ўсе шляхі апублікаваных файлаў у парадку вываду.
- `$path` застаецца даступнай для зваротнай сумяшчальнасці і змяшчае шлях да першага апублікаванага файла. Выкарыстоўвайце `$paths`, калі стужка можа быць падзелена на некалькі файлаў.

`GeneratorService::feed()` вяртае аб'ект `GenerationResultData`. Яго ўласцівасць `$paths` змяшчае тыя ж упарадкаваныя шляхі, а `$records` супастаўляе кожнаму шляху колькасць запісаў, запісаных у адпаведны файл.
