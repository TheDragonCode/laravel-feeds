# Кіраўніцтва па абнаўленні

<PageLead>
Гэта дакументацыя апісвае лінейку выпускаў `1.x`. Перад кожным абнаўленнем правярайце нататкі да выпуску пакета і файл блакіроўкі залежнасцей.
</PageLead>

## Перад абнаўленнем {/* #before-upgrading */}

1. Пераканайцеся, што мэтавая версія падтрымлівае версіі PHP і Laravel праграмы.
2. Зафіксуйце `composer.lock` і бягучы апублікаваны `config/feeds.php`.
3. Запішыце актыўныя рэгістрацыі стужак і месцы выходных файлаў.
4. Запусціце тэсты генерацыі праграмы або згенеруйце тыповыя стужкі не ў вытворчым асяроддзі.

## Прымяненне абнаўлення {/* #apply-update */}

```bash
composer update dragon-code/laravel-feeds --with-all-dependencies
php artisan migrate
```

Параўнайце `config/feeds.php` усталяванага пакета з апублікаванай копіяй праграмы і дадайце новыя ключы ўручную. Не публікуйце паўторна з `--force`: гэта перазапісвае спецыфічныя налады праграмы.

## Праверка {/* #verify */}

- Згенеруйце па адной стужцы для кожнага выкарыстанага фармату.
- Праверце колькасць падзеленых файлаў і іх імёны.
- Праверце генерацыю па раскладзе і праз чаргу.
- Праверце карыстальніцкія мадэлі стужак, пераўтваральнікі, макрасы і падкласы перадусталёвак.
- Параўнайце тыповы вывад з папярэдняй версіяй.

## Адкат {/* #rollback */}

Аднавіце папярэднія `composer.lock` і канфігурацыю, выканайце `composer install` і прымяніце палітыку адкату міграцый праграмы. Згенераваныя файлы — артэфакты разгортвання; аднавіце або згенеруйце іх зноў паводле плана аднаўлення сховішча.
