# Машыннае навучанне

Вы можаце дапамагчы сваёй LLM значна лепш зразумець структуру і правілы гэтага праекта.

Для гэтага імпартуйце інструкцыі з файла [**llms.txt**](https://feeds.dragon-code.pro/llms.txt).

Гэта адзіны аб'яднаны дакумент Markdown, які змяшчае сабраную дакументацыю праекта. Ён прызначаны для выкарыстання як база ведаў для LLM, напрыклад як далучэнне да сістэмнага промпта, корпус для пошуку або карыстальніцкі файл ведаў.

:::note
Захавайце URL і перыядычна імпартуйце файл нанова, каб атрымліваць абнаўленні па меры развіцця праекта.
:::
