# Кіраўніцтва па ўдзеле

Мы **вітаем** ваш унёсак і абавязкова **адзначым** яго.

Мы прымаем унёсак праз Pull Request ва [ўсіх праектах](https://github.com/TheDragonCode) нашай арганізацыі.

## Стыль кода {/* #code_style */}

**Laravel Feeds** прытрымліваецца стандарту афармлення кода [PER-3](https://www.php-fig.org/per/coding-style/) і стандарту аўтаматычнай загрузкі [PSR-4](https://www.php-fig.org/psr/psr-4/).

Каб прымяніць фарматаванне кода, выканайце ў кансолі наступную каманду:

```bash
composer style
```

## Кодэкс паводзін {/* #code_of_conduct */}

Кодэкс паводзін Laravel заснаваны на кодэксе [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Пра любое парушэнне кодэкса можна паведаміць [Andrey Helldar](mailto:helldar@dragon-code.pro):

- Удзельнікі павінны талерантна ставіцца да супрацьлеглых поглядаў.
- Удзельнікі павінны сачыць, каб у іх словах і дзеяннях не было асабістых нападаў і зняважлівых заўваг.
- Тлумачачы словы і дзеянні іншых, удзельнікі заўсёды павінны зыходзіць з добрых намераў.
- Паводзіны, якія можна абгрунтавана лічыць цкаваннем, не дапускаюцца.
