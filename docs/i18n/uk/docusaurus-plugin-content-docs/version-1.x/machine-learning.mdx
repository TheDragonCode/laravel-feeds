# Машинне навчання

Ви можете допомогти своїй LLM краще зрозуміти структуру та правила цього проєкту.

Для цього імпортуйте інструкції з файлу [**llms.txt**](https://feeds.dragon-code.pro/llms.txt).

Це єдиний об’єднаний документ Markdown зі зібраною документацією проєкту. Він призначений для використання як база знань для LLM, наприклад як вкладення до системного промпту, корпус для пошуку або власний файл знань.

:::note
Збережіть URL-адресу й періодично імпортуйте файл повторно, щоб отримувати оновлення проєкту.
:::
