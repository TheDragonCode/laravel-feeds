# Посібник зі внеску

Ми **вітаємо** внески й обов’язково **зазначаємо** їхніх авторів.

Ми приймаємо внески через Pull Request у [всіх проєктах](https://github.com/TheDragonCode) нашої організації.

## Стиль коду {/* #code_style */}

**Laravel Feeds** дотримується стандарту оформлення коду [PER-3](https://www.php-fig.org/per/coding-style/) і стандарту автозавантаження [PSR-4](https://www.php-fig.org/psr/psr-4/).

Щоб застосувати форматування коду, виконайте таку консольну команду:

```bash
composer style
```

## Кодекс поведінки {/* #code_of_conduct */}

Кодекс поведінки Laravel заснований на кодексі [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Про будь-які порушення кодексу поведінки можна повідомити [Andrey Helldar](mailto:helldar@dragon-code.pro):

- Учасники мають терпимо ставитися до протилежних поглядів.
- Учасники повинні уникати особистих нападів і зневажливих зауважень у своїх висловлюваннях та діях.
- Тлумачачи слова й дії інших, учасники мають завжди виходити з добрих намірів.
- Поведінка, яку обґрунтовано можна вважати переслідуванням, не допускається.
