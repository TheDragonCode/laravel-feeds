# Директиви

**Формати:** XML

:::note[Зарезервовані директиви]
- [`@attributes`](#_attributes)
- [`@value`](#_value)
- [`@cdata`](#_cdata)
- [`@mixed`](#_mixed)
- [`@custom`](#_custom)

Директиви доступні лише під час генерування фідів у форматі XML.
:::

## @attributes {/* #_attributes */}

Позначає масив атрибутів.

Для додавання атрибутів до вузла можна використати ключ `@attributes`:

```php source="docs/snippets/advanced-directive-attributes.php" lines="5-"
namespace App\Feeds;

use App\Feeds\Info\AttributesDirectiveFeedInfo;
use App\Feeds\Items\AttributesDirectiveFeedItem;
use App\Models\User;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\Info\FeedInfo;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class AttributesDirectiveFeed extends Feed
{
    public function builder(): Builder
    {
        return User::query();
    }

    public function info(): FeedInfo
    {
        return new AttributesDirectiveFeedInfo;
    }

    public function item(Model $model): FeedItem
    {
        return new AttributesDirectiveFeedItem($model);
    }
}
```

```php source="docs/snippets/advanced-directive-attributes-info.php" lines="5-"
namespace App\Feeds\Info;

use DragonCode\LaravelFeed\Feeds\Info\FeedInfo;

use function fake;

class AttributesDirectiveFeedInfo extends FeedInfo
{
    public function toArray(): array
    {
        return [
            'company' => [
                '@attributes' => ['since' => fake()->year],
            ],

            'url' => config('app.url'),
        ];
    }
}
```

```php source="docs/snippets/advanced-directive-attributes-item.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

class AttributesDirectiveFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name' => $this->model->name,

            'contact' => [
                '@attributes' => [
                    'email' => $this->model->email,
                    'phone' => '555-000-' . $this->model->id,
                ],
            ],
        ];
    }
}
```

Цей код дасть такий результат:

```xml source="docs/snippets/advanced-directive-attributes.xml"
<?xml version="1.0" encoding="UTF-8"?>
<attributes_directive>

<company since="1994"/>
<url>https://example.com</url>

<user>
  <name>User 1</name>
  <contact email="user1@example.com" phone="555-000-1"/>
</user>
<user>
  <name>User 2</name>
  <contact email="user2@example.com" phone="555-000-2"/>
</user>

</attributes_directive>
```

## @value {/* #_value */}

Позначає значення, яке потрібно використати без змін.

:::tip
Значення поля `@value` має бути рядком.
:::

Для додавання значення до вузла можна використати ключ `@value`:

```php source="docs/snippets/advanced-directive-value-item.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

class ValueDirectiveFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name' => [
                '@value' => $this->model->name,
            ],

            'contact' => [
                '@attributes' => ['type' => 'email'],
                '@value'      => $this->model->email,
            ],
        ];
    }
}
```

Цей код дасть такий результат:

```xml source="docs/snippets/advanced-directive-value.xml"
<?xml version="1.0" encoding="UTF-8"?>
<value_directive>

<user>
  <name>User 1</name>
  <contact type="email">user1@example.com</contact>
</user>
<user>
  <name>User 2</name>
  <contact type="email">user2@example.com</contact>
</user>

</value_directive>
```

## @cdata {/* #_cdata */}

Дає змогу використовувати XML-розмітку без перетворення.

:::tip
Значення вузла також можна обгорнути в секцію CDATA. Це дає змогу використовувати зарезервовані символи.
:::

Для додавання CDATA до вузла можна використати ключ `@cdata`:

```php source="docs/snippets/advanced-directive-cdata.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

use function sprintf;

class CdataDirectiveFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name' => [
                '@cdata' => sprintf('<h1>%s</h1>', $this->model->name),
            ],

            'email' => $this->model->email,
        ];
    }
}
```

Цей код дасть такий результат:

```xml source="docs/snippets/advanced-directive-cdata.xml"
<?xml version="1.0" encoding="UTF-8"?>
<cdata_directive>

<user>
  <name><![CDATA[<h1>User 1</h1>]]></name>
  <email>user1@example.com</email>
</user>
<user>
  <name><![CDATA[<h1>User 2</h1>]]></name>
  <email>user2@example.com</email>
</user>

</cdata_directive>
```

## @mixed {/* #_mixed */}

Дає змогу використовувати XML-розмітку безпосередньо в структурі документа.

Щоб вставити фрагменти XML без змін, використовуйте директиву `@mixed`:

```php source="docs/snippets/advanced-directive-mixed.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

class MixedDirectiveFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name' => $this->model->name,

            '@mixed' => <<<XML
                <some>
                    <first>Foo</first>
                    <second>{$this->model->email}</second>
                </some>
                XML,
        ];
    }
}
```

Цей код дасть такий результат:

```xml source="docs/snippets/advanced-directive-mixed.xml"
<?xml version="1.0" encoding="UTF-8"?>
<mixed_directive>

<user>
  <name>User 1</name>
  <some>
    <first>Foo</first>
    <second>user1@example.com</second>
</some>
</user>
<user>
  <name>User 2</name>
  <some>
    <first>Foo</first>
    <second>user2@example.com</second>
</some>
</user>

</mixed_directive>
```

## @custom {/* #_custom */}

Дає змогу вивести масив елементів з однаковими ключами.

Іноді потрібно розмістити масив елементів з однаковими назвами.

Для цього додайте символ `@` на початку назви ключа:

```php source="docs/snippets/advanced-directive-array.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

use function fake;

class ArrayDirectiveFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name' => $this->model->name,

            '@avatar' => [
                fake()->imageUrl(),
                fake()->imageUrl(),
            ],

            '@images' => [
                [
                    '@attributes' => ['name' => fake()->words(asText: true)],
                    '@value'      => fake()->imageUrl(),
                ],
                [
                    '@attributes' => ['name' => fake()->words(asText: true)],
                    '@value'      => fake()->imageUrl(),
                ],
            ],
        ];
    }
}
```

Цей код дасть такий результат:

```xml source="docs/snippets/advanced-directive-array.xml"
<?xml version="1.0" encoding="UTF-8"?>
<array_directive>

<user>
  <name>User 1</name>
  <avatar>https://via.placeholder.com/640x480.png/00ffff?text=aut</avatar>
  <avatar>https://via.placeholder.com/640x480.png/0022dd?text=et</avatar>
  <images name="doloremque distinctio facere">https://via.placeholder.com/640x480.png/0099dd?text=ea</images>
  <images name="fuga odio expedita">https://via.placeholder.com/640x480.png/00cc77?text=sint</images>
</user>
<user>
  <name>User 2</name>
  <avatar>https://via.placeholder.com/640x480.png/00ff99?text=est</avatar>
  <avatar>https://via.placeholder.com/640x480.png/003300?text=non</avatar>
  <images name="distinctio et aliquam">https://via.placeholder.com/640x480.png/0099aa?text=accusantium</images>
  <images name="consequatur soluta nemo">https://via.placeholder.com/640x480.png/0099cc?text=ab</images>
</user>

</array_directive>
```
