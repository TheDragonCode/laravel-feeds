# Сумісність

<PageLead>
Використовуйте визначений Composer граф залежностей як остаточну перевірку сумісності для певного застосунку.
</PageLead>

## Матриця середовища виконання {/* #runtime-matrix */}

<ResponsiveTable label="Laravel Feeds runtime compatibility">

| Компонент | Підтримувані версії |
| --- | --- |
| PHP | `8.2` і новіші версії `8.x`, дозволені обмеженнями встановленого пакета |
| Компоненти Laravel | `11.x`, `12.x`, `13.x` |
| База даних | Будь-яке підключення Laravel, яке підтримують налаштована модель Eloquent і міграція |
| Файлова система | Придатні до запису диски Laravel, які визначаються як `FilesystemAdapter` |

</ResponsiveTable>

Установлений `composer.lock` — остаточне джерело істини для певного застосунку. Composer відхиляє непідтримувані поєднання.

## Формати виведення {/* #output-formats */}

| Формат | Розширення | Вкладені дані | XML-директиви |
| --- | --- | --- | --- |
| XML | `.xml` | Так | Так |
| JSON | `.json` | Так | Ні |
| JSON Lines | `.jsonl` | Одне значення JSON на рядок | Ні |
| CSV | `.csv` | Ні; потрібні стабільні скалярні стовпці | Ні |
| RSS | `.rss` | Так | Так |

## Необов'язкові інтеграції {/* #optional-integrations */}

- Laravel Queue потрібна лише тоді, коли ввімкнено режим черги.
- Laravel Deploy Operations використовується командою `make:feed`, якщо пакет установлено; інакше команда створює міграцію.
- Необов'язкові значення Spatie Laravel Data розпізнаються, якщо цей пакет установлено.
