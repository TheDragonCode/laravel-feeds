# Фіди та дані

<PageLead>
Основний API розділяє джерело даних, зіставлення елементів, метадані фіду, структуру виведення та результат генерування.
</PageLead>

## Feed {/* #feed */}

`DragonCode\LaravelFeed\Feeds\Feed` — базовий клас експорту. Реалізуйте `builder()` і перевизначайте лише ті точки виведення, які потрібні вашому фіду.

<ApiSignature>abstract public function builder(): Builder</ApiSignature>

| Метод | Типове значення | Контракт |
| --- | --- | --- |
| `builder(): Builder` | Абстрактний | Повертає запит Eloquent, який використовується як джерело даних. |
| `item(Model $model): FeedItem` | Новий базовий `FeedItem` | Зіставляє одну модель з елементом виведення. |
| `transformers(): array` | `[]` | Додає на початок назви класів перетворювачів цього фіду. |
| `chunkSize(): int` | `1000` | Розмір блока запиту до бази даних. |
| `perFile(): int` | `0` | Кількість записів у файлі. Нуль вимикає розділення за кількістю. |
| `maxFiles(): int` | `0` | Максимальна кількість вихідних файлів. Нуль означає відсутність обмеження. |
| `header(): string` | Оголошення XML для XML/RSS | Вміст, який записується перед коренем та елементами. |
| `footer(): string` | Порожній рядок | Вміст, який записується після кореня та елементів. |
| `root(): ElementData` | Назва елемента з класу | Визначає кореневий елемент і його атрибути. |
| `info(): FeedInfo` | Порожній `FeedInfo` | Визначає інформацію рівня фіду. |
| `filename(): string` | Назва файлу з класу | Повертає назву вихідного файлу відносно диска. |
| `path($suffix): string` | Шлях, визначений адаптером | Повертає локальний або визначений адаптером шлях. |
| `storagePath($suffix): string` | Назва файлу відносно диска | Повертає шлях для операцій зі сховищем. |
| `storage(): FilesystemAdapter` | Диск `public` | Визначає та перевіряє диск файлової системи Laravel. |
| `format(): FeedFormatEnum` | `Xml` | Повертає налаштований формат виведення. |

`Feed` використовує засоби Laravel `Conditionable` і `Macroable`.

## FeedItem і FeedInfo {/* #feed-item-and-feed-info */}

`FeedItem` отримує поточну модель Eloquent. Його типові значення:

- `name()` повертає базову назву класу моделі у форматі kebab case;
- `attributes()` повертає порожній масив;
- `toArray()` повертає масив моделі.

`FeedInfo::toArray()` повертає порожній масив. Обидва класи використовують `Conditionable` і `Macroable`; успадковуйте їх, коли виведення потребує явної схеми.

## ElementData {/* #element-data */}

`ElementData` — об'єкт лише для читання з трьома властивостями конструктора:

| Властивість | Тип | Типове значення |
| --- | --- | --- |
| `name` | `?string` | `null` |
| `attributes` | `array` | `[]` |
| `beforeInfo` | `bool` | `true` |

Установіть `name` у `null` або порожній рядок, щоб не виводити кореневий елемент. Установіть `beforeInfo` у `false`, щоб записати інформацію фіду перед коренем.

## Результат генерування {/* #generation-result */}

`GeneratorService::feed()` повертає `GenerationResultData`. Його властивість лише для читання `paths` містить опубліковані файли в порядку виведення. Властивість лише для читання `records` зіставляє кожен шлях із кількістю записів у відповідному файлі.

Методи програмного генерування та реєстрації наведено в розділі [служб і контрактів виконання](./runtime.mdx).
