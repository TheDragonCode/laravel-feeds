## Точки розширення {/* #extension-points */}

- Успадкуйте `Feed` або шаблон, щоб визначити джерело даних і контракт виведення.
- Успадкуйте `FeedItem` і `FeedInfo`, щоб керувати серіалізованими даними.
- Реалізуйте `DragonCode\LaravelFeed\Contracts\Transformer` для власного перетворення скалярних значень.
- Поверніть `DragonCode\LaravelFeed\Data\OptionalData`, коли поле потрібно пропустити.
- Зареєструйте макроси для `Feed`, `FeedItem` або `FeedInfo`, щоб додати допоміжні методи застосунку.
