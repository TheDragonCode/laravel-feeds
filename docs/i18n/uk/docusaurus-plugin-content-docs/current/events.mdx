# Події

Під час виконання команди фіди надсилають дві події:

- **`DragonCode\LaravelFeed\Events\FeedStartingEvent`** — подія `FeedStartingEvent` надсилається після попередньої перевірки сховища й шляху, до визначення конвертера та підготовки файлів. Це не означає, що файл чернетки вже існує.
- **`DragonCode\LaravelFeed\Events\FeedFinishedEvent`** — подія `FeedFinishedEvent` надсилається після успішної публікації всіх згенерованих файлів. У разі помилки генерування ця подія не надсилається.

## Контракт завершальної події {/* #finished_event_contract */}

Завершальна подія надає такі публічні властивості:

- `$feed` містить клас згенерованого фіду.
- `$paths` містить шляхи до всіх опублікованих файлів у порядку виведення.
- `$path` залишається доступною для зворотної сумісності та містить перший опублікований шлях. Використовуйте `$paths`, якщо фід можна розділити на кілька файлів.

`GeneratorService::feed()` повертає об’єкт `GenerationResultData`. Його властивість `$paths` містить ті самі впорядковані шляхи, а `$records` зіставляє кожен шлях із кількістю записів у відповідному файлі.
