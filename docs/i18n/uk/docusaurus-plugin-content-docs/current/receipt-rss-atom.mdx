# RSS Atom

## Створення файлів {/* #create_files */}

```bash
php artisan make:feed Rss
```

## Наповнення фіду {/* #filling_the_feed */}

У згенерованому класі замініть `extends Feed` на `extends RssFeedPreset`:

```php source="docs/snippets/receipt-rss-feed.php"
<?php

declare(strict_types=1);

namespace App\Feeds;

use App\Models\News;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;
use DragonCode\LaravelFeed\Presets\RssFeedPreset;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class RssFeed extends RssFeedPreset
{
    public function builder(): Builder
    {
        return News::query()->take(2);
    }

    public function item(Model $model): FeedItem
    {
        return parent::item($model)
            ->guid($model->id) // By default, $model->getKey()
            ->title($model->title)
            ->description($model->content)
            ->category($model->category)
            ->url($model->url)
            ->publishedAt($model->updated_at) // By default, $model->created_at ?? Carbon::now()
            ->additional(['foo' => 'bar']); // By default, []
    }

    public function filename(): string
    {
        return 'rss.xml';
    }
}
```

## Активація {/* #activate */}

Перевірте згенерований файл [операції або міграції](./create-feeds.mdx), а потім виконайте відповідну консольну команду:

```bash
# For Laravel Deploy Operations
php artisan operations

# For Laravel Migrations
php artisan migrate
```

## Генерування фіду {/* #generate_feed */}

Згенеруйте фід такою консольною командою:

```bash
php artisan feed:generate
```
