# Aprendizado de máquina

Você pode ajudar seu LLM a entender muito melhor a estrutura e as convenções deste projeto.

Para isso, importe as orientações do arquivo a seguir: [**llms.txt**](https://feeds.dragon-code.pro/llms.txt).

Esse arquivo é um único documento Markdown consolidado com toda a documentação compilada do projeto. Ele foi criado para servir como base de conhecimento para LLMs, por exemplo, como anexo de um prompt de sistema, corpus de recuperação ou arquivo de conhecimento personalizado.

:::note
Salve a URL e importe o arquivo novamente de tempos em tempos para acompanhar as atualizações do projeto.
:::
