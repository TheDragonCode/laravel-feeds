## Pontos de extensão {/* #extension-points */}

- Estenda `Feed` ou uma predefinição para definir a fonte de dados e o contrato de saída.
- Estenda `FeedItem` e `FeedInfo` para controlar os dados serializados.
- Implemente `DragonCode\LaravelFeed\Contracts\Transformer` para conversão escalar personalizada.
- Retorne `DragonCode\LaravelFeed\Data\OptionalData` quando um campo precisar ser omitido.
- Registre macros em `Feed`, `FeedItem` ou `FeedInfo` para auxiliares da aplicação.
