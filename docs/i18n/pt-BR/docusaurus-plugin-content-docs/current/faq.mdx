# Perguntas frequentes

<PageLead>
Respostas curtas para dúvidas comuns sobre configuração, geração, armazenamento, formatos e memória.
</PageLead>

<details className="faqItem" id="large-datasets">
<summary>O Laravel Feeds exporta milhões de registros?</summary>

Sim. O pacote lê resultados do Eloquent em lotes e grava a saída gradualmente. Mantenha `builder()` lazy, não chame `get()` nem `toArray()` no resultado completo e ajuste `chunkSize()` depois de medir memória e carga do banco.

Veja [desempenho com grandes conjuntos de dados](./performance.mdx).
</details>

<details className="faqItem" id="choose-format">
<summary>Qual formato devo usar?</summary>

Use o contrato exigido pelo consumidor. XML e RSS aceitam diretivas hierárquicas, JSON preserva dados aninhados, JSON Lines serve ao processamento por linha e CSV exige um esquema estável de colunas.

Veja [formatos compatíveis](./supported-formats.mdx).
</details>

<details className="faqItem" id="split-files">
<summary>Um feed pode criar vários arquivos?</summary>

Sim, mas escolha o mecanismo de acordo com o motivo pelo qual os arquivos são diferentes:

- Use `perFile()` e, opcionalmente, `maxFiles()` para dividir um conjunto de dados em partes sequenciais com uma quantidade fixa de registros.
- Use [alvos de feed](./feed-targets.mdx) para criar uma saída filtrada separada para cada parceiro, loja, localidade ou outra chave de negócio.
- Combine os dois mecanismos quando a saída de cada parceiro também puder precisar de várias partes por quantidade de registros.

Veja a [receita de um arquivo de feed por parceiro](./receipt-partner-feeds.mdx) para um exemplo completo.
</details>

<details className="faqItem" id="remote-storage">
<summary>Posso armazenar feeds no S3 ou em outro disco remoto?</summary>

Sim, quando o disco Laravel configurado resolve para um `FilesystemAdapter` gravável. Movimentos remotos podem ser implementados por cópia e exclusão; a substituição atômica não é garantida.

Veja [discos compatíveis](./location.mdx#supported_disks).
</details>

<details className="faqItem" id="disabled-feed">
<summary>Por que um feed desativado foi executado?</summary>

Passar um ID para `feed:generate` executa o feed mesmo quando seu registro está inativo. Sem ID, o comando ignora registros inativos.

Veja [geração de um feed individual](./generation.mdx#single_feed).
</details>

<details className="faqItem" id="optional-field">
<summary>Como omitir um campo opcional?</summary>

Retorne `DragonCode\LaravelFeed\Data\OptionalData` ou `Spatie\LaravelData\Optional` como valor. CSV mantém a coluna e grava um valor vazio; formatos de objeto e XML omitem o campo.

Veja [valores opcionais](./create-feeds.mdx#optional_values).
</details>
