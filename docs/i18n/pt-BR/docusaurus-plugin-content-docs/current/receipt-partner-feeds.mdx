# Vários arquivos de feed por alvo

Esta receita registra um único `PartnerFeed` e usa alvos de feed para gerar vários arquivos XML. Cada alvo fornece parâmetros que `builder()` usa em suas próprias condições de consulta e que `filename()` usa em seu próprio caminho de saída. Os parceiros são apenas o exemplo: um alvo pode representar uma loja, uma localidade, uma região ou qualquer outra condição de negócio.

## Alvos de feed versus perFile() {/* #targets-vs-per-file */}

`perFile()` divide o resultado de uma única consulta em arquivos sequenciais com um limite fixo de registros por arquivo. A consulta e as condições de seleção permanecem as mesmas em todos esses arquivos.

`FeedTarget` executa o feed separadamente para cada alvo. Assim, a aplicação pode usar `target()` para alterar as condições da consulta e o nome do arquivo de cada saída. Os dois mecanismos podem ser combinados: primeiro selecione um conjunto de dados específico do alvo e depois divida-o pela quantidade de registros.

Este exemplo cria os seguintes arquivos de saída por alvo:

```text
storage/app/public/partners/42.xml
storage/app/public/partners/81.xml
```

## Criar o feed {/* #create-feed */}

```bash
php artisan make:feed Partner
```

## Configurar saídas por parceiro {/* #configure-partner-outputs */}

Substitua a classe de feed gerada por:

```php source="docs/snippets/targeted-feed.php"
<?php

declare(strict_types=1);

namespace App\Feeds;

use App\Models\Partner;
use App\Models\Product;
use DragonCode\LaravelFeed\Concerns\InteractsWithFeedTargets;
use DragonCode\LaravelFeed\Contracts\HasFeedTargets;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\FeedTarget;
use Illuminate\Database\Eloquent\Builder;

class PartnerFeed extends Feed implements HasFeedTargets
{
    use InteractsWithFeedTargets;

    public function targets(): iterable
    {
        foreach (Partner::query()->select('id')->lazyById() as $partner) {
            yield $this->makeTarget($partner);
        }
    }

    public function findTarget(string $key): ?FeedTarget
    {
        $partner = Partner::query()->find($key);

        if (! $partner || (string) $partner->getKey() !== $key) {
            return null;
        }

        return $this->makeTarget($partner);
    }

    public function builder(): Builder
    {
        return Product::query()->where(
            'partner_id',
            $this->target()->parameters['partner_id'],
        );
    }

    public function filename(): string
    {
        return "partners/{$this->target()->key}.xml";
    }

    private function makeTarget(Partner $partner): FeedTarget
    {
        return new FeedTarget(
            key       : (string) $partner->getKey(),
            parameters: ['partner_id' => $partner->getKey()],
        );
    }
}
```

`targets()` enumera os parceiros sob demanda nas execuções completas. `findTarget()` resolve as chaves solicitadas explicitamente sem carregar todos os parceiros. `builder()` filtra os produtos do parceiro ativo, e `filename()` atribui um caminho exclusivo a cada parceiro.

## Gerar todos os arquivos de parceiros {/* #generate-all */}

Passe o ID de registro do feed. O comando gera um arquivo para cada parceiro retornado por `targets()`:

```bash
php artisan feed:generate 123
```

Com os parceiros `42` e `81`, os caminhos gerados são:

```text
storage/app/public/partners/42.xml
storage/app/public/partners/81.xml
```

## Gerar arquivos de parceiros selecionados {/* #generate-selected */}

Use a opção repetível `--target` quando apenas parceiros específicos precisarem de arquivos atualizados:

```bash
php artisan feed:generate 123 --target=42
php artisan feed:generate 123 --target=42 --target=81
```

## Dividir cada saída de parceiro por quantidade de registros {/* #split-each-output */}

Adicione `perFile()` quando a saída de um único parceiro também puder ficar grande demais:

```php
public function perFile(): int
{
    return 50000;
}
```

O parceiro `42` poderá gerar `partners/42-1.xml`, `partners/42-2.xml` e as partes seguintes. Essa divisão por quantidade de registros é aplicada separadamente a cada parceiro.
