# Criar feeds

:::note
A maneira mais prática de criar as classes necessárias é usar o plugin [Laravel Idea](https://laravel-idea.com) para o [PhpStorm](https://www.jetbrains.com/phpstorm/).

<ThemedImage
  alt="Laravel Idea"
  sources={{
    light: '/img/laravel-idea.png',
    dark: '/img/laravel-idea_dark.png',
  }}
/>
:::

Para criar uma classe de feed, use o comando `make:feed` no console:

```bash
php artisan make:feed <name>
```

Isso criará um arquivo de feed, por exemplo, `app/Feeds/UserFeed.php`.

Esse comando também pode criar as classes de item e de informações junto com a classe do feed. Para isso, use as opções `--item` e `--info`.

```bash
# Create a feed class and info class
php artisan make:feed <name> --info

# Create a feed class and item class
php artisan make:feed <name> --item

# Create a feed class, item class, and info class
php artisan make:feed <name> --item --info
```

Também existem opções abreviadas:

```bash
# Create a feed class and item class
php artisan make:feed <name> -t

# Create a feed class and info class
php artisan make:feed <name> -i

# Create a feed class, item class, and info class
php artisan make:feed <name> -it
```

:::note
Ao criar um feed, uma operação ou migração também será criada para adicioná-lo ao banco de dados.

Se o projeto usa o [**Laravel Deploy Operations**](https://deploy-operations.dragon-code.pro), uma classe de operação será criada. Caso contrário, será criada uma classe de migração.

Isso é necessário para adicionar e gerenciar as informações do feed no banco de dados.
:::

## Preencher feeds {/* #fill_feeds */}

### Feed {/* #feed */}

Preencha a classe principal do feed. Exemplo:

```php source="docs/snippets/create-feeds-feed.php" lines="5-"
namespace App\Feeds;

use App\Feeds\Items\UserFeedItem;
use App\Models\User;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

class UserFeed extends Feed
{
    public function builder(): Builder
    {
        return User::query()
            ->whereNotNull('email_verified_at')
            ->where('created_at', '>', now()->subYear());
    }

    public function item(Model $model): FeedItem
    {
        return new UserFeedItem($model);
    }
}
```

#### Item do feed {/* #feed_item */}

Preencha a classe de item do feed. Exemplo:

```php source="docs/snippets/generation-feed-item.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

/** @property-read \App\Models\User $model */
class UserFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'name'  => $this->model->name,
            'email' => $this->model->email,
        ];
    }
}
```

##### Valores opcionais {/* #optional_values */}

Para omitir um campo quando seu valor não estiver disponível, retorne uma instância de `DragonCode\LaravelFeed\Data\OptionalData` como valor:

```php source="docs/snippets/optional-values.php" lines="5-"
namespace App\Feeds\Items;

use DragonCode\LaravelFeed\Data\OptionalData;
use DragonCode\LaravelFeed\Feeds\Items\FeedItem;

class UserFeedItem extends FeedItem
{
    public function toArray(): array
    {
        return [
            'id'   => $this->model->id,
            'name' => $this->model->name,

            'cityId' => $this->model->city?->id ?? new OptionalData,

            'createdAt' => $this->model->created_at,
            'updatedAt' => $this->model->updated_at ?? new OptionalData,
        ];
    }
}
```

Os campos opcionais são removidos de objetos JSON e JSON Lines e de elementos XML e RSS, inclusive de campos aninhados comuns. O CSV mantém a posição da coluna e grava um campo vazio.

Se a aplicação usa o [Spatie Laravel Data](https://spatie.be/docs/laravel-data/v4/as-a-data-transfer-object/optional-properties), você pode retornar `Spatie\LaravelData\Optional`. As duas classes de valor opcional são processadas automaticamente.

```php
use Spatie\LaravelData\Optional;

'updatedAt' => $this->model->updated_at ?? Optional::create(),
```

## Feeds direcionados {/* #targeted_feeds */}

Use um feed direcionado quando uma única classe de feed registrada precisar gerar uma saída independente para cada parceiro, loja, localidade ou outro alvo definido pela aplicação. A tabela `feeds` continua com uma única linha para a classe do feed.

Implemente `HasFeedTargets`. O trait `InteractsWithFeedTargets` fornecido pelo pacote implementa o comportamento padrão de `forTarget()` e `target()`; a classe do feed fornece a enumeração sob demanda e a busca direta:

```php source="docs/snippets/targeted-feed.php" lines="5-"
namespace App\Feeds;

use App\Models\Partner;
use App\Models\Product;
use DragonCode\LaravelFeed\Concerns\InteractsWithFeedTargets;
use DragonCode\LaravelFeed\Contracts\HasFeedTargets;
use DragonCode\LaravelFeed\Feeds\Feed;
use DragonCode\LaravelFeed\Feeds\FeedTarget;
use Illuminate\Database\Eloquent\Builder;

class PartnerFeed extends Feed implements HasFeedTargets
{
    use InteractsWithFeedTargets;

    public function targets(): iterable
    {
        foreach (Partner::query()->select('id')->lazyById() as $partner) {
            yield $this->makeTarget($partner);
        }
    }

    public function findTarget(string $key): ?FeedTarget
    {
        $partner = Partner::query()->find($key);

        if (! $partner || (string) $partner->getKey() !== $key) {
            return null;
        }

        return $this->makeTarget($partner);
    }

    public function builder(): Builder
    {
        return Product::query()->where(
            'partner_id',
            $this->target()->parameters['partner_id'],
        );
    }

    public function filename(): string
    {
        return "partners/{$this->target()->key}.xml";
    }

    private function makeTarget(Partner $partner): FeedTarget
    {
        return new FeedTarget(
            key       : (string) $partner->getKey(),
            parameters: ['partner_id' => $partner->getKey()],
        );
    }
}
```

- `targets()` é chamado na definição do feed ainda não configurada e consumido sob demanda quando um comando ou agendamento gera todos os alvos.
- `findTarget()` faz uma busca sensível a maiúsculas e minúsculas para cada chave `--target` explícita. Retorne `null` quando a chave não existir; caso contrário, retorne um alvo com a chave solicitada.
- `FeedTarget::$key` deve ser não vazia, estável, exclusiva dentro da classe do feed e segura para exposição. As chaves não são normalizadas nem sanitizadas e aparecem na saída do console, no JSON do agente, nos eventos e no contexto de falhas.
- `FeedTarget::$parameters` é um snapshot controlado pela aplicação e armazenado nos jobs da fila. O pacote não o interpreta. Mantenha-o pequeno, serializável e sem dados sigilosos; armazene identificadores em vez de modelos Eloquent.
- `target()` retorna o alvo ativo dentro de `builder()`, `filename()` e outros hooks de execução. Ele lança `LogicException` antes que o feed seja configurado com `forTarget()`.

:::warning
Cada alvo deve resultar em um nome de arquivo de saída diferente. Caso contrário, os alvos seguintes sobrescreverão as saídas anteriores. Use uma chave de alvo em um caminho somente quando a aplicação controlar seu formato.
:::

A divisão normal de arquivos continua sendo aplicada separadamente a cada alvo. Por exemplo, `partners/42.xml` se torna `partners/42-1.xml`, `partners/42-2.xml` e assim por diante.

Classes de feed comuns não implementam `HasFeedTargets` e não exigem alterações.

## Formato do arquivo {/* #file_format */}

:::tip
A lista de formatos disponíveis está na página [Formatos compatíveis](./supported-formats.mdx).
:::

Você pode gerar feeds em formatos diferentes. Uma classe de feed só pode ser exportada corretamente para o formato ao qual se destina, devido ao uso de [diretivas](./directives.mdx) e a outras particularidades do formato.

Para aplicar o formato necessário, basta sobrescrever a propriedade `$format` na classe do feed:

```php source="docs/snippets/create-feeds-feed-format.php" lines="5-"
namespace App\Feeds;

use DragonCode\LaravelFeed\Enums\FeedFormatEnum;
use DragonCode\LaravelFeed\Feeds\Feed;
use Illuminate\Database\Eloquent\Builder;

class UserFeed extends Feed
{
    protected FeedFormatEnum $format = FeedFormatEnum::Json;

    public function builder(): Builder
    {
        //
    }
}
```
