# Listar feeds registrados {/* #list_feeds */}

A partir da versão 2.1.0, liste os registros de feeds sem gerar arquivos nem alterar seu estado:

```bash
php artisan feed:list
```

O comando não possui argumentos ou opções específicos. Ele exibe uma tabela com todos os registros, incluindo feeds inativos e excluídos de forma reversível.

| Coluna | Significado |
| --- | --- |
| `id` | ID do registro. |
| `slug` | Slug do registro usado por `feed:generate`. |
| `title` | Título do registro. |
| `expression` | Expressão cron armazenada. |
| `next_run` | Próxima ocorrência do cron no formato ISO 8601 com deslocamento UTC; `null` no JSON quando indisponível. |
| `is_active` | Indica se o registro está ativo. |
| `is_deleted` | Indica se o registro foi excluído de forma reversível. |
| `last_activity` | Data e hora da última geração registrada no formato ISO 8601; `null` no JSON quando não há valor definido. |

Os registros não excluídos aparecem primeiro, seguidos dos registros excluídos de forma reversível. Em cada grupo, os feeds ativos aparecem primeiro, e as linhas são ordenadas por título e ID. Os valores booleanos aparecem como `true` ou `false` no console.

`next_run` usa `app.schedule_timezone` ou, na ausência dele, `app.timezone`. Seu formato é `YYYY-MM-DDTHH:mm:ss±HH:mm`, por exemplo `2025-09-04T09:00:00-04:00`. O valor mostra a próxima ocorrência da expressão cron armazenada mesmo para registros inativos ou excluídos de forma reversível; ele não garante a execução do feed. Se a expressão não tiver uma data de execução possível, como `0 0 31 2 *`, o valor será `null` no JSON e vazio no console.

Use o slug de um registro não excluído para gerar esse feed:

```bash
php artisan feed:generate products
```

Se não houver registros, o console exibirá `No feeds available`.

## Listagem para agentes de IA {/* #list_feeds_agent */}

Dentro de um agente de codificação com IA reconhecido, `feed:list` retorna automaticamente um objeto JSON compacto em uma única linha. Nenhuma opção adicional é necessária. Os campos booleanos continuam sendo booleanos no JSON:

```json
{
  "tool": "feed:list",
  "result": "success",
  "feeds": [
    {
      "id": 1,
      "slug": "products",
      "title": "Products",
      "expression": "0 * * * *",
      "next_run": "2025-09-04T05:00:00+00:00",
      "is_active": true,
      "is_deleted": false,
      "last_activity": null
    }
  ]
}
```

O exemplo está formatado para facilitar a leitura. Uma listagem vazia retorna o mesmo envelope com `"feeds": []`.
