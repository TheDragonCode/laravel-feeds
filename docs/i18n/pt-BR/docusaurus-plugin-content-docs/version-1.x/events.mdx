# Eventos

Os feeds disparam dois eventos durante a execução do comando:

- **`DragonCode\LaravelFeed\Events\FeedStartingEvent`** — O `FeedStartingEvent` é disparado após a verificação preliminar do armazenamento e do caminho, antes da resolução do conversor e da preparação. Isso não significa que já exista um arquivo temporário.
- **`DragonCode\LaravelFeed\Events\FeedFinishedEvent`** — O `FeedFinishedEvent` é disparado depois que todos os arquivos gerados são publicados com sucesso. Uma geração que falha não dispara esse evento.

Os dois eventos expõem `$feed` com a classe do feed gerado e `$target`, que pode ser nulo, com a chave do alvo. Para um feed comum, `$target` é `null`.

## Contrato do evento de conclusão {/* #finished_event_contract */}

O evento de conclusão expõe as seguintes propriedades públicas:

- `$paths` contém todos os caminhos dos arquivos publicados, na ordem de saída.
- `$path` continua disponível para compatibilidade com versões anteriores e contém o primeiro caminho publicado. Use `$paths` quando um feed puder ser dividido entre vários arquivos.

`GeneratorService::feed()` retorna um objeto `GenerationResultData`. A propriedade `$paths` contém os mesmos caminhos ordenados, e `$records` associa cada caminho à quantidade de registros gravados naquele arquivo.
