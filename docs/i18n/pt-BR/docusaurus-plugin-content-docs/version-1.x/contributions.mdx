# Guia de contribuição

Contribuições são **bem-vindas** e receberão os devidos **créditos**.

Aceitamos contribuições por meio de Pull Requests em [todos os projetos](https://github.com/TheDragonCode) da nossa organização.

## Estilo de código {/* #code_style */}

O **Laravel Feeds** segue o padrão de codificação [PER-3](https://www.php-fig.org/per/coding-style/) e o padrão de carregamento automático [PSR-4](https://www.php-fig.org/psr/psr-4/).

Para aplicar a formatação do código, execute o seguinte comando no console:

```bash
composer style
```

## Código de conduta {/* #code_of_conduct */}

O código de conduta do Laravel é baseado no [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Qualquer violação pode ser comunicada a [Andrey Helldar](mailto:helldar@dragon-code.pro):

- Os participantes devem ser tolerantes com opiniões divergentes.
- Os participantes devem garantir que sua linguagem e suas ações não contenham ataques pessoais nem comentários depreciativos.
- Ao interpretar as palavras e ações de outras pessoas, os participantes devem sempre presumir boas intenções.
- Comportamentos que possam ser razoavelmente considerados assédio não serão tolerados.
