# List registered feeds {/* #list_feeds */}

Starting with version 2.1.0, list feed registrations without generating files or changing their state:

```bash
php artisan feed:list
```

The command has no custom arguments or options. It displays a table with all registrations, including inactive and soft-deleted feeds.

| Column | Meaning |
| --- | --- |
| `id` | Registration ID. |
| `slug` | Registration slug used by `feed:generate`. |
| `title` | Registration title. |
| `expression` | Stored cron expression. |
| `next_run` | Next cron occurrence in ISO 8601 with a UTC offset; `null` in JSON when unavailable. |
| `is_active` | Whether the registration is enabled. |
| `is_deleted` | Whether the registration is soft-deleted. |
| `last_activity` | Last recorded generation time in ISO 8601; `null` in JSON when unset. |

Non-deleted registrations appear first, followed by soft-deleted registrations. Within each group, active feeds appear first, then rows are sorted by title and ID. Boolean values appear as `true` or `false` in the console.

`next_run` uses `app.schedule_timezone`, falling back to `app.timezone`. Its format is `YYYY-MM-DDTHH:mm:ss±HH:mm`, for example `2025-09-04T09:00:00-04:00`. It shows the next occurrence of the stored cron expression even for inactive or soft-deleted registrations; it does not guarantee that the feed will run. If the expression has no possible run date, such as `0 0 31 2 *`, the value is `null` in JSON and blank in the console.

Use a non-deleted registration's slug to generate that feed:

```bash
php artisan feed:generate products
```

If no registrations exist, the console displays `No feeds available`.

## AI agent listing {/* #list_feeds_agent */}

Inside a recognized AI coding agent, `feed:list` automatically returns one compact JSON object on a single line. No extra option is required. Boolean fields remain JSON booleans:

```json
{
  "tool": "feed:list",
  "result": "success",
  "feeds": [
    {
      "id": 1,
      "slug": "products",
      "title": "Products",
      "expression": "0 * * * *",
      "next_run": "2025-09-04T05:00:00+00:00",
      "is_active": true,
      "is_deleted": false,
      "last_activity": null
    }
  ]
}
```

The example is formatted for readability. An empty listing returns the same envelope with `"feeds": []`.
