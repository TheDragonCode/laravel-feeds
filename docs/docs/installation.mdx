# Installation & setup

You can install the package via [Composer](https://getcomposer.org):

```bash
composer require dragon-code/laravel-feeds
```

You should publish the [migration](https://github.com/TheDragonCode/laravel-feeds/blob/main/database/migrations/2025_09_01_231655_create_feeds_table.php) and the [config/feeds.php](https://github.com/TheDragonCode/laravel-feeds/blob/main/config/feeds.php) config file with:

```bash
php artisan vendor:publish --tag="feeds"
```

:::warning
**Before running migrations**, check the database connection settings in the `config/feeds.php` file.
:::

Now you can run migrations and proceed to [create feeds](./create-feeds.mdx).

```bash
php artisan migrate
```
